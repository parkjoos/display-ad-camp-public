# 11. 검수 시나리오

구현 완료 판정 기준. 리허설 전 모두 통과해야 한다. "요구" 열은 [00-requirements.md](00-requirements.md) 의 `R-n`.

기본 조건: macOS · Chrome, `start.command` 로 서버 실행, 팀 3개 설정됨, 샘플 데이터 (사진 퀴즈 14카테고리 × 4문제 — 원본 · 확대 · 가림 섞어서, 테스트 이미지 재사용 가능, 이모티콘 퀴즈 3카테고리 × 4문제, 줄줄이 말해요 주제 4개), 득점형 옵션 라운드 3 · 라운드당 2문제 · 선착순 · 동점은 추가 문제. 사진 퀴즈는 E · F · W 장에서는 팀당 대표 끔(0 — 정답 수 방식)으로 보고, 릴레이(기본 팀당 대표 2명, R-62)는 Y 장.
