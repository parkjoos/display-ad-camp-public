# 03. 설정

설정은 진행자가 **앱 화면에서** 바꾸는 값이다. 로컬 서버가 **`state/settings.json` 파일로 저장**한다 (R-28 — 원본은 서버 저장 폴더, git 에는 올리지 않음 — R-37). 브라우저 저장소에는 서버가 꺼졌을 때를 위한 임시 사본만 둔다 ([08-tech.md](08-tech.md) 6장).

## 1. 설정 항목 한눈에

| 범주 | 항목 | 화면 | 저장 범위 |
| --- | --- | --- | --- |
| 팀 | 팀 수, 팀 이름, 팀 색 | 팀 설정 화면 | 앱 전체 (모든 게임 공유) |
| 표시 | 행사 제목 · 부제 덮어쓰기 | 팀 설정 화면 하단 "표시" 구역 | 앱 전체 |
| 게임별 | 카테고리 제외 목록 (첫 룰렛 준비의 초기 선택값) | 게임 홈 | 게임별 |
| 점수 | 라운드(게임) 목록 · 배점(1 · 2 · 3등 점수) · 점수판 입력값 | 배점표 · 종합 점수판 · 게임 홈 배점 구역 | 앱 전체 — 별도 키 `camp-game:scoreboard:v1` ([13-scoreboard.md](13-scoreboard.md) 9-1) |
| 게임별 | ~~라운드 수, 라운드당 문제 수, 문제 순서, 팀당 대표~~ — R-92 로 게임 홈 옵션 없앰. 진행 옵션은 관리 페이지 진행 기본값(데이터 `defaults`)만 | (관리 페이지) | 게임 데이터 |

## 2. 팀 설정 (R-9)

### 2-1. 원칙
- 코드 · 데이터 어디에도 **팀 이름 기본값을 두지 않는다**.
- 처음 실행하면 팀이 설정되지 않은 상태이고, 게임 시작이 막힌다.
- 입력 칸에는 회색 안내 문구(placeholder)만 보인다: "팀 이름을 입력하세요". 이 문구는 값이 아니다.

### 2-2. 화면 구성 (☰ → 팀 설정)

```
┌───────────────────────────────────────────────┐
│  팀 설정                                  [✕]  │
│                                               │
│  팀 수   [ 2 ] [ 3 ] [ 4 ]                     │
│                                               │
│  키  색        팀 이름                          │
│  1   ● ▾   [ 팀 이름을 입력하세요        ]  ▲▼  │
│  2   ● ▾   [ 팀 이름을 입력하세요        ]  ▲▼  │
│  3   ● ▾   [ 팀 이름을 입력하세요        ]  ▲▼  │
│                                               │
│  ── 표시 ──                                    │
│  행사 제목 [ 2026 디광 캠핑               ]    │
│  부제     [ 10월 29일                       ]   │
│                                               │
│          [ 취소 ]              [ 저장 ]        │
└───────────────────────────────────────────────┘
```

| 요소 | 동작 |
| --- | --- |
| 팀 수 | 2 / 3 / 4 중 선택. 처음 값 3 (행사 기준 3팀 — 팀 수는 이름이 아니므로 기본값 허용). 줄이면 아래 행 제거, 늘리면 빈 행 추가 |
| 키 | 득점 단축키 번호 (행 순서 = 키 번호, 표시만) |
| 색 | 팔레트 8색 중 선택 (2-4). 새 행은 아직 안 쓴 색을 순서대로 자동 배정 |
| 팀 이름 | 텍스트 입력 (2-3) |
| ▲▼ | 팀 순서 바꾸기 (= 키 번호 · 스코어보드 순서 변경) |
| 행사 제목 · 부제 | 비우면 `data/app.json` 값 사용. 입력하면 그 값으로 덮어씀 |
| 저장 | 검증 통과 시 저장하고 닫기. 실패 시 해당 칸 빨간 테두리 + 메시지 |
| 취소 · ✕ · `Esc` | 변경 버리고 닫기 (변경이 있으면 "저장하지 않고 닫을까요?" 확인) |

- 이 화면이 열려 있는 동안 게임 단축키(`→`, `Enter` 등)는 동작하지 않는다 (입력 중 오작동 방지). `Enter` = 저장, `Esc` = 취소.
- 키 판정이 `event.code` 기준이라도, 입력 칸에 포커스가 있으면 모든 게임 단축키를 무시한다.

### 2-3. 팀 이름 검증

| 규칙 | 메시지 |
| --- | --- |
| 필수 (앞뒤 공백 제거 후 1자 이상) | "팀 이름을 입력하세요" |
| 최대 10자 (한글 · 영문 · 숫자 · 공백 · 이모지 모두 1자) | "10자 이내로 입력하세요" |
| 팀끼리 중복 금지 (대소문자 · 앞뒤 공백 무시) | "다른 팀과 이름이 같습니다" |
| 줄바꿈 금지 | (입력 자체 차단) |

### 2-4. 팀 색 팔레트

어두운 배경에서 잘 보이고 서로 구분되는 8색. 팀끼리 같은 색은 선택 불가 (이미 쓴 색은 회색 처리).

| 순서 | 이름 | 값 |
| --- | --- | --- |
| 1 | 파랑 | `#3b82f6` |
| 2 | 빨강 | `#ef4444` |
| 3 | 노랑 | `#f59e0b` |
| 4 | 초록 | `#22c55e` |
| 5 | 보라 | `#a855f7` |
| 6 | 분홍 | `#ec4899` |
| 7 | 청록 | `#14b8a6` |
| 8 | 주황 | `#f97316` |

### 2-5. 게임 진행 중 팀 설정 변경

| 변경 | 진행 중 세션이 있을 때 |
| --- | --- |
| 팀 이름 · 색 | 허용. 진행 중 게임 화면에 즉시 반영 (점수는 팀 순번 기준이라 영향 없음) |
| 팀 순서 | 허용하지 않음 — "진행 중인 게임이 있어 순서를 바꿀 수 없습니다" (점수가 다른 팀으로 옮겨지는 사고 방지) |
| 팀 수 | 허용하지 않음 — 같은 메시지 + "게임 홈에서 새로 시작하거나 진행 중 게임을 초기화하세요" |

- "진행 중 세션" = 완료되지 않은 세션이 하나라도 있는 상태 (게임별 세션, [07-state-model.md](07-state-model.md)).

## 4. 게임별 설정 (게임 홈에서 변경)

> **R-92 (10/29)**: 게임 홈의 진행 옵션(라운드 수 · 라운드당 문제 수 · 문제 순서 · 팀당 대표)과 요약 줄 · [기본값으로] 를 없앴다 — 모니터에 띄우는 화면이라 참여자가 알 필요가 없고, 관리 페이지 게임 편집 "진행 기본값" 에서 정한다. 게임 홈에 남은 설정은 **제외 카테고리**(사진 보고 맞추기)뿐. 예전에 게임 홈에서 저장한 옵션 값(`games.<id>.rounds` 등)은 **무시**한다 (지우지는 않음) — 아래 표의 옵션 행은 R-92 전 기록.

| 항목 | 해당 게임 | 기본 | 저장 시점 |
| --- | --- | --- | --- |
| 제외 카테고리 id 목록 (R-6) — 새 게임의 첫 룰렛 준비 선택값. 게임 중 룰렛 준비에서 바꾼 선택은 진행 기록에만 저장되고 여기는 바뀌지 않음 (R-21) | 전체 | 빈 목록 (모두 포함) | 토글할 때마다 즉시 |
| 라운드 수 | 득점형 | 게임 데이터 `defaults.rounds` | 값 변경 즉시 |
| 라운드당 문제 수 | 득점형 | `defaults.questionsPerRound` | 값 변경 즉시 |
| 문제 순서 | 득점형 · 룰렛형 | `defaults.questionOrder` | 값 변경 즉시 |
| 팀당 대표 (`relay`, R-62) — 0 ~ 6, 0 = "끔" | 사진 보고 맞추기 | `defaults.relay` (없으면 사진 2) | 값 변경 즉시. **0 도 저장한다** — 저장값이 없으면 기본 2명이 되므로 |

- 인당 문제(`perRep`, R-64)는 게임 홈 옵션이 아니다 — 관리 페이지 진행 기본값(`defaults.perRep`)만 쓰고, 게임 홈은 요약 줄에 보여만 준다 ([02-data-schema.md](02-data-schema.md) 3-3).
- 팀당 대표가 1명 이상이면 게임 홈에서 라운드당 문제 수 옵션을 숨긴다 (릴레이는 순위가 정해질 때까지 낸다 — [01-app-flow.md](01-app-flow.md) 4-3). 저장값은 그대로 두어 0(끔)으로 돌리면 다시 쓴다.
- 저장값이 범위(0 ~ 6) 밖이면 무시하고 데이터 기본값을 쓴다.
- 룰렛형(줄줄이 말해요)은 **저장하는 게임 설정이 없다** — 라운드 · 문제 수 옵션이 없고 (`D-7`), 게임 홈에 제외 · 문제 순서도 두지 않는다 (R-65 — 주제가 미리 보이면 안 되고, 옵션은 참여자가 알 필요가 없으므로). 문제 순서는 관리 페이지 진행 기본값(`defaults.questionOrder`)만. 예전에 저장한 `excludedCategories` · `questionOrder` 는 남아 있어도 무시한다. 문제 순서는 주제 안에서 [다음 문제] 로 낼 문제를 고르는 법이다 (랜덤 / 작성 순서, R-45). 진행자 화면에서 골라 내는 것은 옵션과 관계없이 된다.
- 진행 옵션은 게임 시작 때 진행 기록에 고정된다 — 바꾼 값은 다음 게임부터.
- 진행 옵션은 데이터 `defaults` 만 쓴다 (R-92 — 저장값은 무시). 게임 홈 [기본값으로] 버튼은 R-92 에서 없앴다.
- 데이터에서 카테고리가 사라지면, 제외 목록의 그 id 는 무시(정리)한다.
- 새로 추가된 카테고리는 기본 **포함**.
- 타이머 옵션은 없다 (R-33). 예전 저장값에 `timerSeconds` 가 남아 있으면 무시하고 다음 저장 때 정리한다.

## 5. 저장 형식

파일: `state/settings.json` (브라우저 임시 사본 키: `camp-game:settings:v1`)

```json
{
  "version": 1,
  "teams": [
    { "name": "<진행자가 입력한 이름>", "color": "#3b82f6" },
    { "name": "<진행자가 입력한 이름>", "color": "#ef4444" },
    { "name": "<진행자가 입력한 이름>", "color": "#f59e0b" }
  ],
  "display": { "title": null, "subtitle": null },
  "games": {
    "photo-quiz": {
      "excludedCategories": ["snack"],
      "rounds": 2,
      "questionsPerRound": 5,
      "questionOrder": "random",
      "relay": 2
    },
    "chain-talk": {
      "excludedCategories": [],
      "questionOrder": "fixed"
    }
  }
}
```

- `teams` 가 없거나 빈 배열 = 팀 미설정.
- 원본이 파일이라 브라우저를 바꾸거나 브라우저 데이터를 지워도, 서버를 다시 켜도 설정은 그대로다. 서버 모드에서는 어느 기기에서 바꾸든 같은 서버 파일이라 모두 같은 설정을 본다. 노트북 모드로 옮길 때는 관리 페이지 백업 (R-37, [08-tech.md](08-tech.md) 5-5).
- 설정 읽기 실패(손상 · 버전 다름) 시: 설정을 버리고 미설정 상태로 시작 + 토스트 "설정을 불러올 수 없어 초기화했습니다".
- 서버가 꺼져 파일에 못 쓰는 동안은 브라우저 사본에 쌓았다가 재연결 시 파일로 올린다. 서버도 꺼지고 브라우저 저장소도 막히면 메모리에만 유지 + 제목 화면 "⚠ 저장 불가 — 새로고침하면 설정이 사라집니다".

## 6. 설정 초기화

- ☰ → 팀 설정 → 하단 "모든 설정 초기화" (작은 글씨 링크) → 확인 → 설정을 빈 상태로 덮어씀. 진행 중 세션이 있으면 세션도 함께 초기화할지 묻는다 (팀 수가 사라지므로 세션 유지 불가 → 함께 삭제).
- 진행 기록 · 점수판까지 한 번에 지우려면 관리 페이지의 상태 초기화 ([04-admin.md](04-admin.md) 3-10, R-32).
