# 게임 — 줄줄이 말해요 (`chain-talk`) · 진행자가 고르는 주제 + 주제별 문제

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 진행 순서 | 1-2 몸풀기 단체게임 |
| 게임 방식 (현장) | 팀원이 차례로 주제에 맞는 말을 이어 간다. 끝까지 이어 가면 성공 200 / 실패 0 |
| **앱이 하는 일** | **진행자가 고른 주제를 고른 순간 모니터에 공개** (R-65 — 원판 · 후보 목록 없음. 예전에는 주제 룰렛, R-12 · `D-7`). 진행자 화면에는 현재 주제의 예시 전체를 보여준다 (R-19). **주제에 문제가 있으면 진행자가 문제를 하나씩 낸다** — 문제 글자("노발○○") · **정답 후보 목록**은 **진행자 화면에만** 나오고 진행자가 읽어 준다. 게임 화면은 문제를 내는 동안에도 주제 카드 그대로 (R-44 → R-65) |
| 앱이 하지 않는 일 | 팀 차례 표시 · 추첨 횟수 · 추첨 완료(요약) 화면 (`D-7`), 타이머, 성공 · 실패 판정(정답 후보에 있는지는 진행자가 보고 말로), 점수 기록, 결과 화면 — 어느 팀 차례인지를 포함해 현장에서 진행자가 말로 진행 |
| 데이터 type | `"roulette"` (카테고리 = 주제. 주제마다 문제를 둘 수 있음 — [../02-data-schema.md](../02-data-schema.md) 4-3) |

## 2. 주제 (카테고리)

| 카테고리 id | 이름 | 아이콘 | 규칙 문구 (`rule`) | 예시 (`examples`, 진행자 참고) |
| --- | --- | --- | --- | --- |
| `idiom` | 사자성어 이어 말하기 | 📜 | 앞 사람이 사자성어 앞 두 글자를 말하면 뒤 두 글자를 이어 말하기 | 노발 → 대발, 대성 → 통곡, 동병 → 상련, 동문 → 서답, 일석 → 이조 |
| `girl-group` | 걸그룹 이름 대기 | 🎤 | 걸그룹 이름을 하나씩, 중복 금지 | 리센느, 소녀시대 |
| `snack` | 봉지과자 이름 대기 | 🍿 | 봉지과자 이름을 하나씩, 중복 금지 | 새우깡, 포카칩 |
| `ends-with-dang` | '당'으로 끝나는 말 | 🔤 | '당'으로 끝나는 낱말을 하나씩, 중복 금지 | 식당, 정당, 서당, 사당 |

- 주제는 데이터로 자유롭게 추가 · 삭제 (☰ → 관리, [../04-admin.md](../04-admin.md)).

### 2-1. 주제별 문제 (R-44)

주제에 **문제**를 넣어 두면 주제를 고른 뒤 진행자가 문제를 하나씩 낸다 (진행자 화면에만 — 읽어 준다, R-65). 줄줄이 말해요는 팀원이 차례로 서로 다른 답을 말하므로 **정답이 하나가 아니라 여럿** — 문제마다 정답 후보를 목록으로 관리한다.

| 필드 | 뜻 | 보이는 곳 |
| --- | --- | --- |
| 문제 글자 (`prompt`) | 진행자가 읽어 줄 글자. 빈칸은 `○` 로 (예: "코스○○", "노발○○") | 진행자 화면만 (R-65 — 예전에는 게임 화면에도) |
| 정답 후보 (`answers`) | 인정할 답 목록 (예: 코스모스 · 코스요리 · 코스피 · 코스트코) — 1개 이상. 다 적지 못해도 된다 — 목록에 없는 답은 진행자가 말로 판정 | 진행자 화면만 (R-65 — 모니터 [정답 후보 표시] 없앰) |
| 메모 (`note`) | 인정 기준 등 진행자 참고 | 진행자 화면만 |

예:

| 주제 | 문제 글자 | 정답 후보 |
| --- | --- | --- |
| (새 주제) 앞 두 글자로 네 글자 | 코스○○ | 코스모스, 코스요리, 코스피아, 코스트코 |
| 사자성어 이어 말하기 | 노발○○ | 노발대발 |

- 문제는 **선택** — 문제가 없는 주제는 지금처럼 주제 카드(아이콘 · 주제 · 규칙)만으로 진행한다.
- 한 주제에 문제를 몇 개든 둘 수 있다. 한 팀이 문제 하나로 이어 말해도 되고(코스○○), 팀원마다 문제를 바꿔도 된다(사자성어 — 노발○○ → 대성○○ …). 몇 문제를 낼지는 진행자가 [다음 문제 ▶] 로 정한다.
- 넣는 곳: 관리 페이지 → 줄줄이 말해요 → 주제의 [문제 관리] ([../04-admin.md](../04-admin.md) 3-13).

## 3. 흐름 — 진행자가 주제를 고르고 고른 순간 공개, 문제는 진행자 화면에만 (R-65)

**원판(룰렛)은 없다.** 룰렛 준비 · 원판처럼 모니터에 후보 주제가 미리 보이면, 팀이 차례를 기다리는 동안 그 주제들의 답을 미리 찾아 둘 수 있다. 그래서 진행자가 진행자 화면에서 주제를 고르고, **고른 순간** 모니터에 그 주제가 나온다. 팀 차례 · 횟수 · 요약 화면은 지금처럼 없다 (`D-7`).

```
[게임 홈]  게임 이름 · 규칙 · 배점 · [게임 시작] 만 (주제 · 옵션 없음)
    │ ▶ 게임 시작
    ▼
[주제 고르는 중]  모니터: 게임 이름 + "주제를 뽑아 주세요" + 지난 주제  ◀────────────────────────────┐
    │ 진행자 화면 주제 버튼 · [🎲 무작위] (topic.pick) — 비상용 게임 창 Enter = 무작위            │
    ▼                                                                                             │
[주제 카드]  큰 아이콘 + 주제 이름 + 규칙  (H: 예시) — 문제를 내는 동안에도 모니터는 이 화면 그대로  │
    │ (문제가 있는 주제) 진행자 [첫 문제 ▶] · [다음 문제 ▶] · 목록 [내기] — N                       │
    │     → 진행자 화면에만 "노발○○" + 정답 후보. 진행자가 읽어 준다 ⟲                            │
    │ → / [다음 주제 ▶] (다음 팀 — 횟수 제한 없음) ─────────────────────────────────────────────────┘
    │ E 끝내기
    ▼
[게임 홈]
```

### 3-1. 게임 홈
- 게임 홈은 모니터에 띄우므로 **참여자가 볼 것만** — 게임 아이콘 · 이름 · 설명, 규칙 문구, 배점("성공 200 · 실패 0"), [▶ 게임 시작] (진행 중이면 [이어하기] · [새로 시작]). 팀 줄 없음 (팀 설정도 필요 없다).
- **주제는 보이지 않는다** (R-65 보완) — 주제 카드 · 주제 수 요약 · 안내 문구 모두 없음. 이름 · 규칙 · 예시는 진행자가 고르는 순간 처음 모니터에 나온다 (미리 보이면 팀이 답을 준비할 수 있으므로).
- **옵션 · 진행자용 안내가 없다** (R-65 보완 3 — "게임 참여자들이 알 이유가 없는 내용") — 문제 순서(랜덤 / 작성 순서)는 관리 페이지 게임 편집의 진행 기본값(`defaults.questionOrder`, 없으면 랜덤)만 쓰고 게임 시작 때 세션에 고정한다 (R-45). 예전에 게임 홈에서 저장한 문제 순서(`games.chain-talk.questionOrder`)는 무시. 진행 중에는 진행자 화면 목록 [내기] 로 언제든 골라 낼 수 있다.
- **제외도 없다** — 후보는 언제나 숨김 아닌 주제 전부, 예전에 저장한 제외(`games.chain-talk.excludedCategories`)는 무시. 안 쓸 주제는 관리 페이지에서 숨기거나, 진행자가 고르지 않으면 된다.
- 시작 조건: 숨김 아닌 주제 ≥ 1. 문제가 없어도 시작할 수 있다.

### 3-2. 주제 고르기 (R-65)
- **모니터**: 게임 아이콘 · 이름 + "주제를 뽑아 주세요" (R-88) + 지난 주제(이미 나온 것만 — 최근 8개). 후보 목록 · 원판 · 남은 문제 수는 보이지 않는다.
- **진행자 화면**: 주제 버튼 목록 (숨김 아닌 주제 전부 — 아이콘 · 이름 · "문제 n" / "문제 모두 냄" · 고른 횟수 "×1"). **누르는 순간 모니터에 공개**된다. [🎲 무작위 (n개 중)] 는 무작위 후보에서 하나. 목록은 가리기(`B`) 대상 (`secret`).
- **무작위 후보** = 숨김 아닌 주제 − 이 게임에서 문제를 다 낸 주제 (`D-26` 의 "자동으로 빠짐" 이 여기로 옮겨 왔다). 이미 고른 주제도 다시 나올 수 있다 (R-16). 후보가 없으면 거절 "무작위로 고를 주제가 없습니다 — 목록에서 직접 고르세요" (진행자 화면에만).
- **직접 고르기는 어느 주제든** — 문제를 다 낸 주제도 고를 수 있다 (다 낸 주제는 주제 카드 · 규칙만으로 진행).
- 예전 룰렛 준비의 넣기 · 빼기(`X` · `A`), 결과 지정(R-48), 회전 · 다시 돌리기는 이 게임에 없다 — 진행자 명령 `roulette.*` 는 거절 "줄줄이 말해요는 룰렛 없이 진행자가 주제를 고릅니다".

### 3-3. 주제 공개 · 문제 — 게임 화면은 주제만, 문제는 진행자 화면에만 (R-65)
- 진행자가 주제를 고르면 모니터에 **주제 카드**(큰 아이콘 + 주제 이름 + 규칙)가 나온다 — 문제가 있는 주제도 같다. 첫 문제가 바로 나오지 않는다 (`D-25` 그대로 — 규칙을 설명하고 팀이 준비한 뒤 시작).
- 문제는 진행자가 [첫 문제 ▶] 로 시작한다 (게임 화면 키 없음 — R-85). **문제 글자 · 정답 후보 · 메모는 진행자 화면에만** — 진행자가 문제를 읽어 주고("노발!") 팀원이 답한다. 신서유기 · 지구오락실처럼 PD 가 말로 내는 방식이고, 문제가 없는 주제(걸그룹 이름 대기 등)와 같은 진행이다.
- 게임 화면은 문제를 내는 동안에도 **주제 카드 그대로** — 문제가 바뀌어도 화면이 다시 그려지지 않는다. 모니터에 정답 후보를 띄우는 기능([정답 후보 표시] · `H`)은 없다 (R-44 의 모니터 문제 · 정답 후보 표시를 R-65 에서 뺌).

| 요소 | 게임 화면 (주제 카드) | 진행자 화면 |
| --- | --- | --- |
| 아이콘 · 주제 이름 · 규칙 | 화면 중앙 대형 | 위에 |
| 예시 | 진행자 [예시 표시] 로 표시 / 숨김 (게임 화면 `H` 는 R-78 에서 없앰) (기본 숨김) | 항상 전체 |
| 문제 글자 | **없음** | 크게 ("노발○○") |
| 정답 후보 · 메모 | **없음** | 정답 후보 전체 (가나다순) · 메모 |
| 팀 · 차례 · 횟수 | 표시하지 않음 (`D-7`) | 같음 |

- 처음 R-65 에서는 "문제가 있는 주제는 주제 카드 없이 주제와 첫 문제가 함께" 모니터에 나왔다 — 고르자마자 문제가 보여 취소하고, 모니터에는 문제를 아예 띄우지 않기로 했다 (R-65 보완 2).
- **문제 고르기** (`D-24`, R-45) — 후보는 언제나 그 주제의 문제 중 **이 게임에서 아직 안 낸 것**. 숨긴 문제는 나오지 않는다. 같은 주제를 다시 골라도 이미 낸 문제는 다시 안 나온다.

| 방법 | 누르는 것 | 고르는 법 |
| --- | --- | --- |
| 순서대로 · 무작위 | 진행자 화면 [첫 문제 ▶] · [다음 문제 ▶] | 관리 페이지 진행 기본값 **문제 순서** (게임 시작 때 고정) — 랜덤(기본): 남은 것 중 무작위 / 작성 순서: 관리 페이지 문제 목록 순서대로 남은 것 중 첫 번째 |
| 진행자가 고르기 | 진행자 화면 **"이 주제 문제" 목록**의 [내기] | 고른 문제가 바로 지금 문제가 된다 (주제 카드에서는 첫 문제로). 옵션과 관계없이 언제나 |

- 진행자 화면 "이 주제 문제" 목록: 문제 글자만(정답 후보는 지금 문제만), 관리 페이지 순서. 지금 문제 ▶ · 이 게임에서 낸 문제는 흐리게 "냄" · 남은 문제마다 [내기]. 작성 순서 옵션이면 [다음 문제 ▶] 로 나올 문제에 "다음" 표시.
- [다음 문제 ▶] — 남은 문제가 없으면 버튼이 없고 진행자 화면에 "이 주제의 문제를 다 냈습니다 — [다음 주제 ▶] 하면 이 주제는 무작위에서 빠집니다".
- 모니터에 주제 카드를 띄워 둔 채 현장 게임을 진행한다. 진행자는 진행자 화면의 문제를 읽어 주고, 정답 후보를 보며 말로 판정한다.
- 다음 팀 차례가 되면 진행자 화면 [다음 주제 ▶] (예전 [다시 추첨 ▶]) → 주제 고르기. 횟수 제한은 없다.
- 다 끝나면 진행자 화면 [끝내기] → 게임 홈. 줄줄이 말해요는 게임 화면 키가 없다 (R-85 — 예전 `Enter` 무작위 주제 · `N` 문제 · `→` 다음 주제 · `E` 끝내기). 결과를 모아 보여주는 화면은 없다.

## 4. 이전 이동 · 저장

- `←` 는 없다 (R-74) — 잘못 고른 주제 · 낸 문제를 게임 화면에서 되돌릴 수 없다. 진행자 화면 [다음 주제 ▶] 로 넘어간다 (낸 문제는 "냄" 으로 남음).
- 고른 주제 목록 · 낸 문제 · 무작위 후보는 세션에 저장 → 새로고침 · 앱 재실행 후에도 같은 주제 카드 · 문제로 이어하기 ([../07-state-model.md](../07-state-model.md) 3-3 · 6장).
- [끝내기] 하면 세션은 완료 상태가 된다 — 제목 화면 이어하기 카드에 나오지 않고, 게임 홈은 다시 [▶ 게임 시작] (새 세션 — 문제도 처음부터 다시 나올 수 있음).
- 진행 중에 관리 페이지에서 문제를 고치면 바로 반영된다 (정답 후보 추가 등). 이미 낸 문제를 지우면 다음에 불러올 때 건너뛴다.

## 5. 점수

- 게임 화면은 점수를 다루지 않는다 (R-12). 성공 200 / 실패 0 은 진행자가 **종합 점수판**의 "줄줄이 말해요" 행(성공 · 실패 방식)에 팀별로 입력한다 ([../13-scoreboard.md](../13-scoreboard.md)).
- 게임 홈에는 배점("성공 200 · 실패 0")을 보여주고 그 자리에서 수정할 수 있다 (R-24).
