# 게임 — 이모티콘 퀴즈 (`emoji-quiz`) · 탑재 준비

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 진행 순서 | 2-1 전원 퀴즈 (2-2 사진 보고 맞추기 바로 앞) |
| 문제 준비 | **이모티콘 담당자** (R-15) |
| 앱 | 담당자가 준비해 오면 **바로 탑재**되도록 게임 · 카테고리 · 화면 · 입력 경로를 미리 준비 (R-15). 탑재(어드민 붙여넣기)는 누구나 한다 (`D-14`) |
| 참가 | **19명 모두** — 문제를 전체에 내고 먼저 외친 사람이 답한다 (R-49). 처음엔 라운드마다 각 팀 대표 1명이었음 (`D-4`) |
| 진행 | 이모지 나열을 보고 영화 · 속담 · 노래 제목을 맞힌다 |
| 게임에서 세는 것 | 맞힌 사람이 속한 팀에 정답 1개 (문제당 1팀). 결과는 정답 수 순서 + 카테고리별 정답 수 (R-90 — 라운드 대신 카테고리 묶음) (R-22) |
| 점수 | **정답 1개당 50점** (R-49) — 종합 점수판 라운드 "이모티콘 퀴즈"(방식 정답 수, 1개당 50, [../13-scoreboard.md](../13-scoreboard.md) 3장). 게임 화면 스코어보드 · 결과 · 진행자 화면에 점수(정답 수 × 50)를 보여주고, 끝나면 점수판에 정답 수로 채운다. 처음엔 시트대로 "영화 · 속담 · 노래 제목" 각각 1등 100 / 2등 50 / 3등 0 이었음 (`D-11`) |
| 데이터 type | `"emoji"` ([../02-data-schema.md](../02-data-schema.md) 4-2) |

## 2. 카테고리 (미리 등록, 문제 0개)

출처: 위키 · 시트 "이모티콘 퀴즈 - 영화 / 속담 / 노래제목"

| 카테고리 id | 이름 | 아이콘 | 설명 | 질문 문구 (`prompt`) |
| --- | --- | --- | --- | --- |
| `movie` | 영화 | 🎬 | 이모지로 표현한 영화 제목은? | 이 영화의 제목은? |
| `proverb` | 속담 | 📜 | 이모지로 표현한 속담 · 사자성어는? | 이 속담은? |
| `song` | 노래 제목 | 🎵 | 이모지로 표현한 노래 제목은? | 이 노래의 제목은? |

- 문제가 0개인 동안 메뉴에는 "이모티콘 퀴즈 · 준비 중" 으로 보이고, 게임 홈의 [게임 시작] 은 "문제가 없습니다" 로 비활성.
- 담당자가 다른 카테고리를 원하면 어드민에서 추가.

## 3. 진행 방식 — 룰렛 · 라운드 없이 진행자가 문제를 고른다 (R-90)

이모티콘 퀴즈는 **룰렛이 없다** (R-90 — "이모티콘 퀴즈는 룰렛 필요 없어 그냥 진행자가 고르는대로 진행"). 진행자가 진행자 화면에서 문제를 하나씩 골라 [내기] 하면 모니터에 바로 그 문제가 나온다. 문제 · 정답 화면 · 맞힌 팀 · 점수 · 결과 · 점수판 채우기는 득점형 공통 흐름 그대로다.

```
[게임 홈]  이름 · 설명 · 규칙 · 배점 · 팀 · [게임 시작] (카테고리 카드 · 제외 · 옵션 없음)
    │ ▶ 게임 시작
    ▼
[문제 고르기]  모니터: 게임 이름 + "카테고리를 골라 주세요" + 카테고리 카드(남은 문제 n)  ◀──────┐
    │ 카드 클릭 (그 카테고리 문제 하나, R-91) · 진행자 화면 카테고리 → 문제 [내기]          │
    ▼                                                                                     │
[문제]  머리줄 "😀 🎬 영화 · 3번째 문제" — [힌트 단계 ▶] · [💡 힌트] → [정답 공개] (Enter)    │
    ▼                                                                                     │
[정답]  맞힌 팀 · [없음] → 다음 문제 [내기] (바로 [문제]) 또는 [카테고리 목록 ▶] (Enter) ──┘
    │ [종료] (문제를 다 냈으면 문제 고르기에서 [결과 보기 ▶] · Enter)
    ▼
[결과] → 점수판 채우기
```

- **문제 고르기 화면** (05-screens 4-13): 모니터에는 카테고리 카드(아이콘 · 이름 · "남은 문제 n", 다 낸 카테고리는 흐리게 "모두 냄")만 — 참가자가 카테고리를 말하면 그 카드를 **클릭**해 그 카테고리 문제 하나를 바로 낸다 (문제 순서 옵션대로, R-91). 특정 문제를 내려면 진행자 화면 [내기]. 문제는 다 냈으면 "모든 문제를 냈습니다".
- **진행자 화면** (12-host-view 4-11): 카테고리 버튼 → 그 카테고리의 남은 문제(이모지 · 정답, 데이터 순서) → [내기]. 문제 고르기 화면과 정답 화면에 있다. 정답 화면에서 맞힌 팀도 [없음] 도 정하지 않고 [내기] 하면 "맞힌 팀(정답자)을 체크하지 않았습니다" 를 묻는다 (R-87 과 같음).
- **이 게임에서 낸 문제**는 목록에서 빠진다. 숨김 아닌 카테고리 · 문제는 모두 고를 수 있다 (게임 홈 제외 없음, 예전에 저장한 제외는 무시).
- **라운드가 없다** — 라운드 소개 · 라운드 종료 화면 · [한 문제 더] · [한 라운드 더] · [팀 점수에 반영] 이 없다. 기록은 카테고리마다 한 묶음(`picks` — 처음 고른 순서대로, 같은 카테고리 문제는 그 묶음 뒤에)이라 결과 · 기록 · 통계의 "라운드별 정답 수" 는 카테고리별 정답 수가 된다. 끝은 진행자가 [종료] 로 정한다.
- R-90 전에 시작한 진행 기록(룰렛으로 뽑은 라운드)은 이어서 진행할 수 있다 — 라운드 소개 · 라운드 종료 화면에 있었으면 그대로 넘기고, 다음부터는 문제 고르기. 라운드로 뽑아 두고 안 낸 문제는 후보로 돌아온다.

참가 · 점수는 그대로다: 대표 없이 19명 모두가 답하고 정답 1개마다 50점을 준다 (R-49).

| 항목 | 사진 보고 맞추기 | 이모티콘 퀴즈 |
| --- | --- | --- |
| 게임 홈 · 카테고리 제외 · 옵션 | 카테고리 카드 · 제외 · 라운드 · 팀당 대표 | 없음 — 이름 · 규칙 · 배점 · 팀 · 시작만 (R-90) |
| 문제 정하기 | 라운드마다 룰렛 준비 → 룰렛 → 라운드 소개 | 진행자가 문제를 하나씩 골라 [내기] — 라운드 없음 (R-90) |
| 질문 문구 | 카테고리마다 ("이 사진의 정체는?" 등) | 카테고리마다 ("이 영화 제목은?", "이 속담은?", "이 노래 제목은?") |
| 문제 화면 메인 | 사진 (원본 · 확대 · 가림) | 이모지 대형 표시 (순차 공개 연출) |
| 진행자 [힌트 단계 ▶] (예전 `Z` 키 — R-78) | 한 단계 힌트 (축소 · 가림 제거) | (순차 공개 문제) 이모지 하나 더 공개 |
| 정답 공개 · 힌트 · 득점 · 정답 기록 고치기 · 결과 · 진행자 화면 (타이머 없음 — R-33) | 같음 | 같음 |
| 참가 · 점수 (R-49) | 라운드마다 팀 대표 · 정답 수 → 등수 배점 | 19명 모두 · 정답 1개당 50점 (화면에 점수, "+50") |

- 영화 · 속담 · 노래를 골고루 하려면 진행자가 카테고리를 바꿔 가며 고른다 — 모니터 카테고리 목록의 남은 문제 수를 참고 (R-90 전에는 룰렛 준비에서 한 카테고리를 빼고 돌렸음).
- **진행 (R-49)**: 대표를 부르지 않는다. 문제를 내면 19명 누구나 외칠 수 있고, 먼저 외친 사람이 답한다 (틀리면 다음 사람 — 선착순, [README.md](README.md) 4장). [정답 공개] 뒤 진행자 화면에서 **맞힌 사람이 속한 팀**을 고른다 — 앱에는 사람 이름이 없다.
- **점수 (R-49)**: 맞힌 팀에 정답 1개 = 50점. 게임 화면 스코어보드는 정답 수 대신 점수(정답 수 × 50)를, 맞히면 "+50" 을 보여준다. 결과도 점수와 정답 수를 함께 보여주고, 동점이어도 점수가 같으므로 추가 문제 안내는 띄우지 않는다. 결과 뒤 "점수판에 채울까요?" → [확인] 이면 점수판 "이모티콘 퀴즈" 행에 팀별 정답 수가 들어간다 (점수 = 정답 수 × 50). 1개당 점수는 배점표 · 게임 홈 [배점 수정] 에서 바꾼다.
- 카테고리마다 따로 등수로 채점하던 방식(`D-11` 처음 기본값 "영화 · 속담 · 노래 각각 100/50/0")은 R-49 로 바뀌었다. 다시 필요하면 점수판 라운드 설정에서 등수 라운드를 카테고리마다 추가한다 ([../13-scoreboard.md](../13-scoreboard.md) 8장).

## 4. 문제 화면 (이모지 표시)

| 요소 | 규칙 |
| --- | --- |
| 이모지 크기 | 메인 영역 높이의 40% (1080p 기준 약 300px). 이모지 개수가 많으면 한 줄에 맞게 자동 축소, 최소 120px. 6개 초과면 두 줄 허용 |
| 공백 | `emojis` 의 공백은 단어 구분으로 넓은 간격(이모지 폭 0.6배)으로 표시 |
| 폰트 | 시스템 이모지 폰트 (macOS: Apple Color Emoji) — 오프라인 OK |
| 순차 공개 (`reveal: "sequential"`) | 처음엔 첫 이모지만, 나머지는 같은 크기의 흐린 "?" 자리 표시. 진행자 [힌트 단계 ▶] 마다 하나씩 공개 (뒤집히는 효과 0.4초). [◀] 로 하나 숨기기 |
| 정답 공개 | 남은 이모지 모두 공개 → 아래에 정답 텍스트 |
| 정답 이미지 (`answerImage`, 선택 — R-39) | 정답 공개 때 이모지(이미지 문제면 그 이미지) 대신 정답 이미지로 교차 페이드 (0.4초, 순차 공개로 남은 이모지가 뒤집힌 뒤) → 정답 띠. 사진 보고 맞추기의 정답 이미지와 같다 ([photo-quiz.md](photo-quiz.md) 5-3). "정답 글자 숨기기" 를 켜면 정답 띠 없이 이미지만 (R-41) |
| 이미지 문제 (`image`) | 사진 보고 맞추기처럼 이미지 표시 (확대 없음) |

## 5. 담당자 → 앱 탑재 절차

1. 담당자가 구글 시트에 템플릿 형식으로 작성 ([../02-data-schema.md](../02-data-schema.md) 6-1)
   - 열: 카테고리 · 이모지 · 정답 · 힌트 · 메모 · 순차공개
   - 템플릿 시트는 구현 시 `docs/templates/emoji-quiz-template.tsv` 로 함께 제공 (구글 시트에 가져오기 가능)
2. 누구든(`D-14`) 서버 주소의 `/admin` → PIN 입력 → 이모티콘 퀴즈 → [표 붙여넣기] ([../04-admin.md](../04-admin.md) 3-9)
3. 시트에서 표 범위 복사 → 붙여넣기 → 미리보기 확인 → [등록]
4. 게임 홈에서 문제 수 확인 → 리허설 1회
5. 끝 — 서버에 바로 저장되어 모두에게 보인다 (커밋 · 푸시 없음, R-37)

- 이모지를 이미지(카톡 이모티콘 캡처 등)로 준비해 오면: 어드민 문제 추가에서 이미지로 개별 등록.
- 정답 이미지(포스터 · 앨범 표지)는 표에 담을 수 없다 — 표로 등록한 뒤 문제 편집에서 "정답 이미지" 로 하나씩 넣는다 (R-39).
- 예상 탑재 시간: 30문제 기준 10분 이내 (붙여넣기 1회 + 확인).

## 6. 출제 가이드 (담당자 참고용)

| 카테고리 | 좋은 문제 | 피할 것 |
| --- | --- | --- |
| 영화 | 제목 단어를 직접 이모지로 표현 (🪱🏠 기생충, 🧊👸 겨울왕국) | 줄거리를 알아야만 풀리는 문제 |
| 속담 | 핵심 사물 2~4개 (🐦🐦🪨 일석이조, 🐸🌊 우물 안 개구리) | 이모지가 7개 이상인 긴 속담 |
| 노래 | 제목이 짧고 유명한 곡 | 아이돌 팬만 아는 수록곡 |

- 이모지는 macOS · iOS 에서 보이는 모양 기준으로 확인 (다른 기기에서 고른 이모지는 모양이 다를 수 있음).
- 정답 인정 기준이 애매하면 "메모" 열에 적는다 (게임 화면에는 안 나오고 진행자 화면에만 표시).
