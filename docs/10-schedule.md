- [ ] 터미널 창은 노트북 화면에 두고 닫지 않기

### 앱
- [ ] (노트북 모드로 진행할 때만) 최근 백업 파일을 노트북 관리 페이지 [백업 올리기] → 새로고침

- [ ] ☰ → 진행자 화면 → 노트북 화면으로 옮기기 → 터미널의 PIN 입력 → "● 실시간" 확인
- [ ] 팀 설정: 팀 수 · 이름 · 색 (팀 정하기 게임 결과에 맞춰 당일 수정 가능)
- [ ] 각 게임 홈: 카테고리 제외 · 라운드 수 · 문제 수 확인
- [ ] 메뉴에 "⚠ 데이터 오류" 없음, 게임 홈에 "이미지를 찾을 수 없습니다" 없음
- [ ] 전체화면에서 3m 거리 가독성 (질문 문구 · 정답 · 점수 · 주제)
- [ ] ☰ → 관리 → 새 창으로 `/admin` 이 열리고 PIN 을 묻는지, 탭을 닫고 다시 열면 다시 묻는지 (`D-9`, R-31)
- [ ] 게임 진행 중 관리 페이지에서 정답 오타를 고쳐 저장 → 모니터 게임 화면은 그대로, 진행자 화면 정답이 바뀌는지
- [ ] 룰렛 준비: 카테고리 빼기 · 다시 넣기가 원판에 바로 반영, 다시 돌리기 시 준비로 돌아오는지
- [ ] 사진 퀴즈 룰렛 준비에 14개 카테고리가 한 화면(2열)에 보이는지, 14칸 원판 글자가 3m 거리에서 읽히는지 (`D-5`)
- [ ] 룰렛 회전 · 확정, 같은 카테고리 재당첨 시 다른 문제가 나오는지
- [ ] 배점표: 게임별 1 · 2 · 3등 점수가 시트와 같은지, 수정 모드로 고치고 끄기 (모니터에 보여줄 땐 수정 모드 끔)
- [ ] 종합 점수판: 등수 · 성공 여부 입력 → 합계 · 순위, 발표 화면 공개 순서
- [ ] 사진 퀴즈 연출별 1문제씩: 원본 · 확대(`Z` 단계 축소) · 가림(`Z` 상자 제거) · 정답 공개(정답 이미지)
- [ ] 진행자 화면이 게임 화면을 따라 바뀌는지 (문제 이동 · 정답 공개 · 득점)
- [ ] 진행자 화면 버튼만으로 한 라운드 진행: [룰렛 돌리기] → [확정] → [첫 문제] → [정답 공개] → 맞힌 팀 선택 → [다음 문제] → … → [종료] → 결과 → 점수판 채우기
- [ ] 진행자 화면을 닫고 게임 화면 비상용 키로도 진행되는지
- [ ] 이모티콘 퀴즈 1라운드 통과: 순차 공개 · 정답 공개
- [ ] 줄줄이 말해요: [게임 시작] → 진행자 화면에서 주제 고르기(모니터에 후보가 안 보이는지) → 주제 카드 → (문제 있는 주제) [첫 문제] — 모니터에 문제가 안 나오는지 → [다음 주제] 3번 → [끝내기] (팀 차례 표시 없음 — `D-7`), 진행자 화면에 예시 표시
- [ ] 결과 화면 공개 순서 · 공동 등수 표시
- [ ] 새로고침 후 이어하기, 서버를 껐다 켜도 진행 유지
- [ ] 리허설 후 서버 관리 페이지 → [백업 내려받기] (리허설 기록 보관) → 상태 초기화 → [리허설 기록 지우기] (진행 기록 · 점수판 입력값만, 팀 · 배점 · 옵션 유지 — R-32). 서버라 바로 모두에게 반영

### 콘텐츠
- [ ] 사진 속에 정답 글자(상표 · 제목 · 자막)가 노출되지 않음 (가림 상자 위치 확인)
- [ ] 이모지가 진행 노트북(macOS)에서 의도한 모양으로 보임
- [ ] 문제 난이도 · 중복 정답 없음, 카테고리당 문제 수 충분
