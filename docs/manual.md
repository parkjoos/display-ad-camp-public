# 진행자 설명서 — 2026 디광 캠핑 게임

**2026 디광 캠핑**(10/29 목) 게임 진행을 맡은 분들을 위한 설명서입니다. 접속 방법, 진행자 화면 쓰는 법, 당일 순서, 문제가 생겼을 때 할 일을 담았습니다.

> 자세한 동작 규칙은 스펙 문서([docs/README.md](README.md))에 있습니다. 이 문서는 "현장에서 무엇을 누르면 되는지"만 정리했습니다.
>
> 현장에서는 **앱 안에서 한 화면 요약**을 볼 수 있습니다 — 진행자 화면 맨 위 **[❓ 설명서]**, 관리 페이지 맨 위 **[📖 설명서]**.

## 1. 한눈에

이 앱은 서버(Vercel)에서 돌아가는 웹 페이지입니다. 화면은 세 개입니다. 아래 `<서버 주소>` 는 운영자가 알려 줍니다.

| 화면 | 주소 | 어디에 띄우나 | 하는 일 |
| --- | --- | --- | --- |
| **게임 화면** | `<서버 주소>/` | 모니터에 연결한 노트북 (전체화면) | 참가자가 보는 화면 — 룰렛 · 문제 · 정답 · 결과 · 점수판. **진행 버튼이 없습니다** |
| **진행자 화면** | `<서버 주소>/host` | 진행자 휴대폰 (노트북 창도 가능) | 지금 문제의 **정답** 보기 + 진행 버튼 (룰렛 · 정답 공개 · 맞힌 팀 · 다음 문제 · 종료 · 결과) |
| 관리 페이지 | `<서버 주소>/admin` | 노트북 | 문제 · 카테고리 추가 · 수정, 점수 입력, 백업 |

- 세 화면 모두 **6자리 PIN** 으로 들어갑니다. PIN 은 운영자에게 따로 받습니다. **문서 · 공개 채널에 적지 마세요.**
- 인터넷만 되면 어디서나 열립니다. 캠핑장 와이파이 말고 **휴대폰 LTE · 5G** 로 접속합니다.
- 주소를 아는 사람은 누구나 PIN 화면까지 올 수 있습니다 — PIN 을 지켜 주세요.

```
 진행자 휴대폰 1 ─┐
 진행자 휴대폰 2 ─┼─ LTE · 5G ─▶ 서버 ◀─ 인터넷 ─ 노트북 ─▶ 모니터 (게임 화면)
 (노트북 창)     ─┘
```

## 2. 행사 전에 해 둘 일

| 언제까지 | 할 일 |
| --- | --- |
| 주소 · PIN 을 받은 뒤 | 휴대폰을 와이파이 끄고 LTE · 5G 로 → 진행자 화면 주소 열기 → PIN 입력 → 위쪽에 **"● 실시간"** 이 보이면 성공 |
| 그때 같이 | 진행자 화면을 **홈 화면에 추가** (사파리: 공유 → 홈 화면에 추가 / 크롬: ⋮ → 홈 화면에 추가) |
| 10/27 (화) 리허설 | 실제로 한 라운드를 진행해 보기 — 휴대폰 두 대 이상 동시 접속, 버튼이 모니터에 반영되는지 |

- 한 번 입장하면 **7일 동안** 다시 PIN 을 묻지 않습니다. 서버가 재시작돼도 그대로입니다. PIN 이 바뀌면 다시 입장합니다.

## 3. 접속하기

### 3-1. 진행자 (휴대폰)

1. 와이파이를 끄고 LTE · 5G 로
2. 홈 화면의 아이콘 또는 `<서버 주소>/host`
3. PIN 6자리 → [입장]
4. 위쪽 오른쪽이 **● 실시간** 이면 준비 끝 (○ 재연결 중이면 7장)

### 3-2. 게임 화면 (모니터 노트북)

1. 모니터 연결 → macOS 디스플레이 설정에서 **"확장" 모드** (⚠ **미러링 금지** — 미러링이면 노트북의 진행자 화면 정답이 모니터에도 나옵니다)
2. 노트북도 인터넷 연결 (휴대폰 핫스팟 등 — 캠핑장 와이파이가 불안하면)
3. 브라우저로 `<서버 주소>/` → PIN → 제목 화면
4. 창을 모니터로 옮기고 **`F`** 로 전체화면
5. 노트북 화면에도 진행자 화면을 띄우려면 게임 화면 **☰ → 진행자 화면** (같은 브라우저라 PIN 을 다시 묻지 않습니다)
6. 노트북 절전 · 화면 꺼짐 · 알림 끄기 (방해 금지 모드)
7. **소리** — 정답 영상(뮤직비디오 · 명대사 — 5-2)을 위해 노트북 소리를 스피커로 (모니터 HDMI 스피커 또는 블루투스 스피커), 음량 확인. 게임 화면을 연 뒤(새로고침한 뒤에도) **게임 화면을 한 번 클릭**해 두세요 — 브라우저는 클릭하기 전의 창에서 소리 나는 영상을 막습니다

## 4. 누가 무엇을 하나

| 하는 일 | 어디서 |
| --- | --- |
| 게임 고르기 · 게임 시작 · 팀 설정 · 배점표 · 종합 점수판 | **게임 화면** 노트북 — 좌상단 ☰ 메뉴 |
| 게임 진행 (룰렛 · 정답 공개 · 맞힌 팀 · 다음 문제 · 결과 · 점수판 채우기) | **진행자 화면** (휴대폰) |
| 정답 · 오답 판정 | **진행자가 말로** (앱에 판정 버튼은 없습니다) |
| 문제 오타 고치기 · 점수 고치기 | 관리 페이지 (노트북) |

- 진행자 화면은 **여러 명이 동시에** 열어도 됩니다. 모두 같은 화면이 보이고 누가 눌러도 같은 동작입니다. 거의 동시에 누르면 먼저 도착한 것만 적용되고, 나머지는 "화면이 바뀌어 적용하지 않았습니다" 알림이 뜹니다 — 연타해도 두 번 넘어가지 않습니다.
- 진행 중에는 진행자 한 명이 버튼을 맡고, 다른 진행자는 정답 확인용으로 보는 것을 권합니다.

## 5. 진행자 화면 사용법

### 5-1. 화면 구성

| 위치 | 내용 |
| --- | --- |
| 맨 위 | 게임 · 라운드 · 카테고리, **● 실시간 / ○ 재연결 중**, [가리기], [나가기] |
| 문제 카드 | 문제 번호 · 진행 상태 · **정답(가장 크게)** · 메모(인정 · 불인정 기준 등) · 힌트 |
| 화면 버튼 | [힌트 단계 ▶] (확대 사진 한 단계 축소 · 가림 상자 하나 벗기기 · 이모지 하나 더), [◀] 되돌리기, [💡 힌트] 표시 · 숨김 |
| 진행 버튼 | [정답 공개] · [다음 문제 ▶] · [종료] · 머리줄 [📝 정답 기록] (지난 문제 고치기) |
| 아래 | 이번 라운드 문제 목록 · 팀별 정답 수. 아직 안 낸 문제의 **[다음으로]** 를 누르면 그 문제가 바로 다음 차례가 됩니다. 그 아래 **후보** 는 이번 라운드 카테고리에서 랜덤에 안 뽑힌 문제 — [다음으로] 를 누르면 바로 다음에 나오고, 라운드 문제 수는 그대로라 목록의 마지막 문제가 후보로 돌아갑니다 (지금이 라운드 마지막 문제면 한 문제 더 붙습니다) |

- **[가리기]**: 주변 사람이 휴대폰 화면을 볼 때 정답 · 목록을 흐리게 가립니다 (버튼은 그대로 눌림). 다시 누르면 보입니다.
- **[나가기]**: 그 브라우저에서 연 게임 화면 · 관리 페이지까지 함께 잠깁니다. ⚠ **모니터 게임 화면을 띄운 노트북에서는 누르지 마세요.** 휴대폰에서는 눌러도 됩니다.

### 5-2. 사진 보고 맞추기 진행 순서

이모티콘 퀴즈는 룰렛 · 라운드 없이 진행자가 문제를 고릅니다 — 5-4 (R-90).

| 단계 | 진행자 화면에서 | 말로 하는 것 |
| --- | --- | --- |
| 1. 룰렛 준비 | 카테고리 목록에서 [넣기/빼기] (모두 넣으려면 [모두 넣기]). 사진은 문제가 모자란 카테고리가 "부족 · 남은 3/4" 로 꺼져 있습니다 — 넣을 수 없음 | "팀마다 두 분씩 나와 주세요" (팀당 대표 2명 — 대표 호출 · 카테고리 고르기 순서는 자유) |
| 2. 룰렛 | **[룰렛 돌리기]** → 멈추면 **[확정]** (마음에 안 들면 [다시 돌리기]). 나올 카테고리를 미리 정하려면 돌리기 전에 **결과 지정** 줄에서 고르기 — 그 조각에 멈춥니다 (이번 한 번만, 모니터엔 표시 없음) | |
| 3. 라운드 소개 | **[첫 문제 ▶]** | "첫 번째 게임은 ○○ 입니다" |
| 4. 문제 | 필요하면 [힌트 단계 ▶] · [💡 힌트]. 정답은 휴대폰에서 확인 | 먼저 외친 팀부터 답할 기회 (선착순), 틀리면 다음 팀. **말로 판정** |
| 5. 정답 공개 | 누가 맞혔든, 아무도 못 맞혔든 **[정답 공개]**. 정답 영상이 있는 문제(🎬)는 모니터에서 영상이 먼저 나오고 끝나면 정답 글자 — 기다리기 싫으면 **[⏭ 영상 끝내기]** | |
| 6. 맞힌 팀 | 정답 공개 뒤 나타나는 **[팀 이름]** 버튼 하나 (아무도 못 맞혔으면 **[없음]**). 잘못 눌렀으면 다른 팀을 누르면 바뀝니다. 사진은 맞힌 대표가 라운드에서 빠지고, 대표를 모두 내보낸 팀 버튼은 "🥇1등 · 빠짐" 으로 꺼집니다 (버튼 아래 "팀A 2/2 🥇1등 · 팀B 1/2 · 팀C 0/2") | |
| 7. 다음 | **[다음 문제 ▶]** → 4로. 팀당 대표를 끈 경우(0): 라운드 마지막 문제면 진행자 화면에 **"라운드가 종료되었습니다"** — 더 내고 싶으면 **[한 문제 더 ▶]** → 4로 (같은 카테고리, 몇 번이든), 끝내려면 **[라운드 종료 ▶]**. 사진: **한 팀만 남으면** **"🏁 순위가 정해졌습니다"** → **[라운드 종료 ▶]** (그 전에는 [다음 문제 ▶] 가 필요한 만큼 문제를 더 냅니다 — [한 문제 더] 는 없음) | |
| 7-1. 라운드 종료 | 모니터에 팀별 이번 라운드 점수 · 누적 (사진은 **이번 라운드 순위** · 맞힌 대표). **[팀 점수에 반영]** → 종합 점수판에 이번 라운드 점수 (라운드 등수대로 1등 100 · 2등 50) → **[다음 라운드 ▶]** → 1로 (다음 대표). 맞힌 팀을 고쳐야 하면 [◀ 라운드로 돌아가기] → 고친 뒤 [다시 반영] | "이번 라운드는 ○○팀이 가장 많이 맞혔습니다" · 사진: "다음 두 분씩 나와 주세요" |
| 8. 결과 | 계획한 라운드가 끝나면 라운드 종료 화면에서 **[결과 보기 ▶]** → **[다음 순위 공개 ▶]** 로 하위 순위부터. 사진은 라운드 배점을 더한 **게임 점수**("150점") 순서입니다. 더 하고 싶으면 그 옆 **[한 라운드 더 ▶]** → 1로 (몇 번이든) | |
| 9. 동점 | 동점이 있으면 **추가 문제 고르기** — 카테고리를 누르고 문제의 [내기] (이 게임에서 낸 문제는 목록에 없음) → 동점 팀끼리 선착순 → [정답 공개] → 맞힌 팀 → [결과로 ▶] | |
| 10. 점수판 채우기 | 모두 공개하면 진행자 화면에 "종합 점수판에 채울까요?" → **[확인]** (고칠 게 있으면 [점수 고치기]) | |

- **문제당 맞힌 팀은 1팀**, 오답 감점은 없습니다. 앱은 **맞힌 개수만** 세고(사진은 라운드 등수 — 아래), 1 · 2 · 3등 점수는 종합 점수판에서 합칩니다.
- 앱은 시간을 재지 않습니다 (타이머 없음). 언제 정답을 공개할지는 진행자가 정합니다.
- 라운드 수 · 라운드당 문제 수(관리 페이지 진행 기본값)는 **계획**일 뿐입니다 — 문제를 더 내려면 라운드 끝 안내에서 [한 문제 더 ▶] (사진 릴레이는 없음), 라운드를 더 하려면 라운드 종료 화면에서 [한 라운드 더 ▶], 일찍 끝내려면 [종료].
- 가림 문제의 [힌트 단계 ▶] 는 상자를 하나씩 벗기지만 **마지막 상자(제목 등 정답)는 [정답 공개] 때만** 벗겨집니다. 상자가 1개인 문제는 힌트 단계 버튼이 없습니다.
- **정답 영상** (사진 보고 맞추기 — 뮤직비디오 장면 · 명장면 명대사 등, 문제 카드에 🎬 배지): [정답 공개] 를 누르면 모니터에서 그 장면의 유튜브 구간이 자동으로 나오고, 끝나면 정답 글자가 나옵니다. 영상이 나오는 동안에도 맞힌 팀 버튼은 누를 수 있습니다 (모니터 표시는 영상이 끝난 뒤). 진행자 화면 영상 카드에서 [⏸ 일시정지] · [▶ 계속] · [⏭ 영상 끝내기] · [↺ 영상 다시 재생].
- 정답을 공개하지 않고 [다음 문제 ▶] 를 누르면 "정답을 공개하지 않고 넘어갈까요?" 를 묻습니다.
- 정답 화면에서 맞힌 팀도 [없음] 도 누르지 않고 [다음 문제 ▶] · [라운드 종료 ▶] 를 누르면 "맞힌 팀(정답자)을 체크하지 않았습니다. 이대로 다음으로 넘어갈까요?" 를 묻습니다 — 아무도 못 맞혔으면 [없음] 을 먼저 누르면 묻지 않습니다 (R-87).
- 라운드 · 문제가 남아 있어도 **[종료]** → 확인 → 바로 결과로 갈 수 있습니다.
- 지난 문제의 맞힌 팀을 고치려면 맨 위 **[📝 정답 기록]** → 그 문제의 팀 버튼 · [없음] (게임 화면은 그대로). 사진 보고 맞추기는 팀마다 [대표1] [대표2] 로 맞힌 사람까지 고칩니다.
- **사진 보고 맞추기는 팀당 대표 방식**입니다 — 라운드마다 팀마다 새 대표 **2명**(관리 페이지 게임 편집 → 진행 기본값 "팀당 대표" 로 바꿀 수 있음, 0 = 끔)이 **함께** 나옵니다 (3팀이면 6명이 모여 동시에 풉니다).
  - 먼저 외친 쪽부터 답하는 것은 같고, **맞힌 사람은 인당 문제만큼 맞히면 그 라운드에서 빠집니다**.
  - 정답 공개 뒤 진행자 화면 "맞힌 사람" 에서 **팀의 [대표1] · [대표2]** 를 누릅니다 (게임 화면 노트북에서 오른쪽 점수 띠의 그 팀 "1" · "2" 묶음을 클릭해도 같습니다). 대표1 · 대표2 가 누구인지는 팀이 정합니다. 앱이 사람마다 맞힌 수를 세어, 다 맞혀 빠진 사람 버튼은 "빠짐" 으로 꺼집니다 (R-94).
  - 대표가 **모두 빠진 순서**가 그 라운드 1 · 2 · 3등입니다. **한 팀만 남으면 라운드가 끝나고** 남은 팀이 꼴찌입니다.
  - 모니터 오른쪽 점수 칸은 대표마다 한 줄 — "1 ●○" · "2 ○○" (그 사람이 맞힌 ● · 남은 ○), 다 빠진 팀은 "🥇 1등".
  - **인당 문제**(관리 페이지 게임 편집 → 진행 기본값, 기본 1)를 2로 두면 한 사람이 2문제까지 맞히고 빠집니다 — 팀은 2명 × 2문제 = 4개를 맞히면 끝 (R-64). 누가 빠지면 진행자 화면에 "🚪 팀A 대표1 — 2문제를 다 맞혀 빠집니다" 가 나오니 말로 알려 주세요 (R-94).
  - 라운드마다 문제는 관리 페이지의 **라운드당 문제 수**(예: 12)만큼 뽑습니다 (최소 4개 — 3팀 × 2명, R-95). 순위가 정해지면 다 내지 않아도 라운드가 끝나고 남은 문제는 다음 라운드로 돌아갑니다. 뽑은 문제를 다 내도 순위가 안 정해지면 [다음 문제 ▶] 가 같은 카테고리에서 하나씩 더 냅니다. 그래도 카테고리 문제가 떨어지면 "🏁 이 카테고리에 낼 문제가 없습니다" — [라운드 종료 ▶] (다 못 맞힌 팀은 맞힌 수로 등수).
  - 남은 문제가 4개보다 적은 카테고리는 이 게임에서 쓰지 않습니다 (게임 홈 "4개 필요", 룰렛 "부족"). 문제를 넣을 때 카테고리마다 **6개 이상** 넣어 주세요.
  - 3라운드 × 2명 = 팀당 6명이 한 번씩 나옵니다 (7명 팀은 한 명이 남음 — 팀이 정하거나 [한 라운드 더 ▶]).

### 5-3. 줄줄이 말해요 (진행자가 고르는 주제)

룰렛이 없습니다 — 후보 주제가 모니터에 미리 보이면 팀이 답을 미리 준비할 수 있어서, 진행자가 고르고 **고르는 순간** 모니터에 공개됩니다 (R-65).

1. 게임 화면 노트북: ☰ → 줄줄이 말해요 → [게임 시작] — 모니터는 "주제를 뽑아 주세요"
2. 진행자 화면: 주제 버튼을 누르거나 **[🎲 무작위]** → 모니터에 바로 그 **주제 카드**(이름 · 규칙). 진행자 화면에서 **예시 전체**를 볼 수 있고, 모니터에 보여주려면 [예시 표시]
3. 문제가 있는 주제(사자성어 이어 말하기 · 속담 이어 말하기 등)는 규칙을 설명한 뒤 **[첫 문제 ▶]** → **진행자 화면에만** 문제("노발○○")와 **정답 후보 전체**(가나다순)가 나옵니다. 모니터는 주제 카드 그대로입니다 — 문제를 소리 내어 읽어 주고("노발!"), 팀원이 말하는 답이 후보에 있는지 보고 말로 판정합니다 (후보에 없어도 맞으면 인정)
4. 같은 주제로 더 하려면 **[다음 문제 ▶]** (이 게임에서 안 낸 문제 — 관리 페이지 게임 편집의 "문제 순서" 가 랜덤이면 무작위, 작성 순서면 관리 페이지 순서). 특정 문제를 내려면 진행자 화면 "이 주제 문제" 목록에서 **[내기]**
5. 다음 팀은 **[다음 주제 ▶]** → 2로 (횟수 제한 없음). 다 끝나면 **[끝내기]**. 문제를 다 낸 주제는 [🎲 무작위] 에서 빠집니다 (직접 고르면 주제 카드로 진행)
6. 잘못 골랐으면 [다음 주제 ▶] 로 넘어갑니다 — 되돌리는 키(`←`)는 없습니다 (R-74)

- 팀 차례 · 점수는 앱이 세지 않습니다. 결과는 ☰ → 종합 점수판에 입력합니다.

### 5-4. 이모티콘 퀴즈 (진행자가 고르는 문제)

룰렛 · 라운드가 없습니다 — 진행자가 문제를 하나씩 골라 냅니다 (R-90). 대표 없이 **19명 모두**에게 문제를 냅니다.

1. 게임 화면 노트북: ☰ → 이모티콘 퀴즈 → [게임 시작] — 모니터에 **카테고리 목록**(영화 · 속담 · 노래 제목, 남은 문제 수)과 "카테고리를 골라 주세요"
2. 게임 화면 노트북에서 참가자가 말한 **카테고리 카드를 클릭**하면 그 카테고리 문제가 바로 나옵니다 (R-91). 또는 진행자 화면 "문제 고르기": 카테고리를 누르면 남은 문제(이모지 · 정답)가 나옵니다 → 낼 문제의 **[내기]** → 모니터에 바로 그 문제 (라운드 소개 없음, 머리줄 "🎬 영화 · 3번째 문제")
3. 문제: 필요하면 [힌트 단계 ▶] · [💡 힌트]. 19명 중 먼저 외친 사람부터 답할 기회 — **말로 판정** → **[정답 공개]**
4. 맞힌 사람이 속한 **[팀 이름]** (아무도 못 맞혔으면 **[없음]**)
5. 다음 문제: 정답 화면 아래 "다음 문제 고르기" 목록에서 바로 **[내기]**. 모니터를 카테고리 목록으로 돌려 참가자에게 카테고리를 고르게 하려면 **[카테고리 목록 ▶]** → 2로. 맞힌 팀도 [없음] 도 누르지 않고 넘기면 "맞힌 팀(정답자)을 체크하지 않았습니다" 를 묻습니다
6. 끝낼 때 **[종료]** → 확인 → 결과 → **[다음 순위 공개 ▶]** → "종합 점수판에 채울까요?" → **[확인]**. 문제를 다 내면 모니터에 "모든 문제를 냈습니다" — 진행자 화면 **[결과 보기 ▶]**

- **정답 1개당 50점**입니다 — 게임 화면 · 진행자 화면에 점수가 보이고(맞히면 "+50"), [확인] 하면 점수판 "이모티콘 퀴즈" 행에 정답 수가 들어갑니다. 1개당 점수는 배점표에서 바꿉니다. 점수가 같으면 그대로 (추가 문제 없음).
- 이 게임에서 낸 문제는 목록에서 빠집니다. 결과 · 기록의 "라운드별 정답 수" 는 카테고리별 정답 수입니다.
- 라운드 종료 화면 · [팀 점수에 반영] 은 없습니다 — 점수판은 결과에서 한꺼번에 채웁니다.

| "화면이 바뀌어 적용하지 않았습니다" | 다른 진행자가 먼저 눌렀거나 화면이 막 바뀐 것 — 화면을 보고 필요하면 다시 누르기 |

| 정답 영상 소리가 안 남 · "🔇 소리가 꺼져 있습니다" | 모니터 노트북에서 **게임 화면을 한 번 클릭** — 이어서 소리가 납니다 (브라우저가 클릭 전에는 소리를 막음). 그래도 안 나면 노트북 음량 · 출력 장치(스피커) 확인 |

| 휴대폰을 아예 못 씀 | 노트북 화면에 진행자 화면(☰ → 진행자 화면)을 띄워 진행하거나, 게임 화면에서 **비상용 키**(8장) |

## 8. 비상용 키 (게임 화면 노트북)

진행자 화면을 쓸 수 없을 때 게임 화면 키보드로 `Enter` 로 넘기기 · 정답 공개 정도는 할 수 있습니다 — 맞힌 팀 · 점수 고치기 · 힌트 · 영상 · 끝내기 · 한 문제 더 · 한 라운드 더 · 팀 점수 반영 · 추가 문제는 진행자 화면에서만 되고, 줄줄이 말해요는 게임 화면 키가 없습니다 (R-78 · R-80 · R-81 · R-83 · R-85). 게임 화면 ☰ 메뉴의 [도움말] 을 누르면 그 화면에서 쓸 수 있는 키가 나옵니다 (`?` · `M` 키는 없음 — R-73).

| 키 | 동작 |
| --- | --- |
| `F` | 전체화면 |
| `Enter` | 룰렛: 돌리기 / 확정 / (문제 없음) 결과로 — 카테고리 넣기 · 빼기는 진행자 화면에서만 (R-72 · R-79) |
| `Backspace` | 룰렛 정지 후: 돌리기 전으로 (다시 돌리기 — 넣은 카테고리 그대로, R-84) |
| `Enter` | 라운드 소개: 첫 문제 / 문제: 정답 공개 → 다음 문제 · 라운드 종료 (맞힌 팀을 안 정했으면 "이대로 넘어갈까요?" 확인창 — 한 번 더 `Enter`, R-86) / 라운드 종료: 다음 라운드 · 결과 / 결과: 다음 순위 공개 (R-82 · R-85) |

## 9. 문제 넣기 · 고치기 (관리 페이지)

- 노트북에서 `<서버 주소>/admin` (또는 게임 화면 ☰ → 관리) → PIN. 관리 페이지는 **탭을 새로 열 때마다** PIN 을 묻습니다.
- 저장하면 **바로 서버에 반영**됩니다. 따로 올리거나 커밋할 필요가 없습니다. 게임 진행 중에 고치면 진행자 화면의 정답은 바로 바뀌고, 모니터에 떠 있는 문제 화면은 그대로 둡니다.
- 사진 문제 · 이모티콘 문제 · 줄줄이 말해요 주제 넣는 법: 저장소 [README](../README.md) 3장.
- 정답 공개 때 보여줄 **정답 이미지**(포스터 · 앨범 표지 등)는 사진 · 이모티콘 문제 모두 문제 편집의 "정답 이미지 (선택)" 에 넣습니다. 정답 공개 때 글자 띠가 필요 없으면(이미지에 정답이 보이거나, 확대 문제처럼 원본 사진이면 충분할 때) ☐ **정답 글자 숨기기** 를 켭니다 — 정답 이미지가 없어도 켤 수 있습니다.
- 가림 상자는 **정답 글자를 덮는 상자를 마지막 번호**로 두세요 (마지막 상자는 정답 공개 때만 벗겨짐).
- **정답 영상** (사진 문제): 문제 편집의 "🎬 정답 영상 — 유튜브" 에 영상 주소와 시작 · 끝 시간(`83` 또는 `1:23`)을 넣습니다. 유튜브 [공유] → "시작 시간" 을 체크해 복사한 주소를 붙이면 시작 칸이 채워집니다. **[▶ 구간 미리보기]** 로 꼭 확인하세요 — 공식 뮤직비디오 중에는 다른 사이트에서 재생을 막아 둔 것이 있습니다 ("⚠ 다른 사이트에서 재생할 수 없는 영상" 이면 다른 영상으로). 유튜브 "클립" 주소는 쓸 수 없습니다 (원본 영상 주소 + 시간).
- 잘못 저장했으면 [백업 목록] 에서 그 시점으로 복원할 수 있습니다 (게임별 최근 20개).
