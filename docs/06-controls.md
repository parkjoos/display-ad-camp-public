# 06. 조작

## 0. 조작 원칙 (R-26, R-29)

## 1. 키 입력 공통 규칙

| 규칙 | 내용 |
| --- | --- |
| 키 판정 | `event.code` 기준 (`KeyZ`, `Digit1`, `ArrowRight` 등) → 한글 입력 상태에서도 동작 |
| 반복 입력 | 키를 누르고 있을 때의 반복(`event.repeat`) 무시 → 점수 중복 방지 |
| 입력 칸 포커스 | 팀 설정 · 게임 홈 숫자 칸 · 종합 점수판 등 입력 중에는 게임 단축키 전부 무시 (`Esc` · `Enter` 만 그 화면 규칙대로) |
| 오버레이 | 도움말 · 확인창 · 메뉴가 열려 있으면 그 오버레이의 키만 동작 |
| 룰렛 회전 중 | `Esc` 외 모든 키 무시 (메뉴는 ☰ 로 열 수 있음) |
| 애니메이션 중 | 애니메이션을 끝 상태로 건너뛰고 입력 처리 |
| 수정 키 | `Cmd` · `Ctrl` · `Alt` 가 함께 눌리면 무시 (브라우저 단축키와 충돌 방지). `Shift` 조합만 사용 |

## 2. 전역 키 (어느 화면에서나)

| 키 | 동작 |
| --- | --- |
| `F` | 전체화면 토글 (종합 점수판에서 성공 · 실패 라운드 칸을 고른 상태면 "실패" 입력 — [13-scoreboard.md](13-scoreboard.md) 6장) |
| `Esc` | 열린 오버레이 · 메뉴 닫기 → 없으면 전체화면 해제 (브라우저 기본) |
| (확인창) `Enter` / `Esc` | 확인 / 취소 — `Space` 로는 확인되지 않는다 (R-75) |

- 메뉴 · 도움말 키(`M` · `?` · `/`)는 없다 (R-73) — 메뉴는 좌상단 ☰ 버튼, 도움말은 메뉴의 [도움말].

## 3. 화면별 키

- **`←` · `PageUp`(이전 · 되돌아가기)은 게임 화면 어디에도 없다** (R-74). 지난 문제를 고치는 것은 진행자 화면 [◀ 라운드로 돌아가기] · [📝 정답 기록] 으로. 방향키는 종합 점수판의 칸 이동에만 쓴다 (게임 홈 방향키 이동은 R-76 에서 뺌).

### 3-1. 제목 화면

제목 화면 전용 키는 없다 (R-73) — 메뉴는 좌상단 ☰, 이어하기는 이어하기 카드의 [이어하기] 버튼. 예전 `→` · `Enter` · `Space`(메뉴 열기) · `C`(이어하기)는 없앴다.

### 3-2. 햄버거 메뉴

| 키 | 동작 |
| --- | --- |
| `↑` / `↓` | 항목 이동 |
| `Enter` | 선택 |
| `Esc` | 닫기 (☰ · 바깥 클릭도) |

### 3-3. 게임 홈

게임 홈 전용 키는 없다 (R-76) — 화면에서 클릭으로 하는 것은 단축키를 두지 않는다. 카드 클릭 = 제외 토글, [▶ 게임 시작] · [▶ 이어하기] · [새로 시작](확인창) 은 버튼으로. 클릭한 뒤 포커스가 남은 카드 · 버튼도 `Enter` · `Space` 로 다시 눌리지 않는다. 쓸 수 있는 키는 공통 키(`F` · `Esc`)와 열린 확인창의 `Enter` · `Esc`, 숫자 · 배점 입력 칸 안의 키뿐. 예전 `Tab` · 방향키 이동, `Space` 제외 토글, `Enter` 시작 · 이어하기, `N` 새로 시작은 없앴다.

### 3-4. 룰렛 (준비 → 회전 → 정지, R-21)

| 키 | 준비 (카테고리 고르기) | 회전 중 | 정지 후 |
| --- | --- | --- | --- |
| `Enter` | 돌리기 (넣은 항목 0개면 무시 + 안내, 1개면 회전 없이 바로 결정) | 무시 | 확정 |
| `Space` · `→` · `PageDown` | 무시 (돌리기는 `Enter` — R-75) | 무시 | 무시 — 확정은 `Enter` 만, 다시 돌리기는 `Backspace` · 진행자 화면 [다시 돌리기] (R-79 · R-84) |
| `Backspace` | 무시 | 무시 | 돌리기 전으로 — 준비 단계로 돌아감 (넣은 카테고리 유지, 방금 결과는 버림). 진행자 화면 [다시 돌리기] 와 같음 (R-84) |
| `E` · `R` | 무시 — 게임 일찍 끝내기는 진행자 화면 [종료], 진행 초기화는 게임 홈 [새로 시작] (R-77 · R-80) | 무시 | 무시 |

- 기본 조작은 진행자 화면의 [넣기/빼기] [모두 넣기] [룰렛 돌리기] [확정] [다시 돌리기] 버튼 (0장). **넣기 · 빼기는 진행자 화면에서만** — 게임 화면에는 목록이 없고 예전 키 `↑` `↓` `X` `A` 도 없앴다 (R-72). 원판은 클릭해도 반응하지 않는다 (보여주기 전용).
- `Enter` 돌리기는 언제나 무작위다. 결과 지정은 진행자 화면에만 있다 (R-48, [12-host-view.md](12-host-view.md) 4-8).
- 숫자 키로 카테고리를 고르지 않는다 (게임 화면 숫자 키는 R-81 에서 모두 없앰).
- "더 출제할 문제가 없습니다" 화면도 `Enter` (결과로) 만 — `→` · `PageDown` 은 R-79, `E` · `R` 은 R-77 에서 뺐다.

- **이모티콘 퀴즈 (R-90)** 는 라운드 소개 · 라운드 종료 화면이 없다 — 문제 `Enter` = 정답 공개, 정답 `Enter` = **문제 고르기**(카테고리 목록)로 (맞힌 팀 미지정이면 위와 같은 확인창). 문제 고르기 화면에서는 `Enter` 만 — 남은 문제가 없을 때 결과로, 그 밖에는 아무 일 없음. 문제는 **카테고리 카드 클릭**(그 카테고리 문제 하나, R-91) 또는 진행자 화면 [내기] 로 고른다 — 클릭 뒤 포커스가 남은 카드는 `Enter` · `Space` 로 눌리지 않는다. 룰렛 키(3-4)는 없다.
- **사진 보고 맞추기 팀당 대표 방식 (R-94)** — 정답 화면에서 오른쪽 점수 띠의 **대표 묶음("1" · "2")을 클릭**하면 그 팀 · 대표가 맞힌 것으로 (진행자 화면 "맞힌 사람" 버튼과 같다). 인당 문제를 채운 사람 · 대표를 모두 내보낸 팀의 묶음은 눌리지 않는다. 키는 늘리지 않는다 (숫자키는 위 표대로 무시).

### 3-7. 룰렛형 — 주제 고르기 · 주제 카드 · 문제 (`D-7`, R-44, R-65)

**줄줄이 말해요는 게임 화면 키가 없다** (R-85) — 공통 키(`F` · `Esc`)만. 예전 주제 고르기 화면의 `Enter`(무작위 주제) · `E`(끝내기), 주제 카드의 `N`(첫 문제 · 다음 문제) · `→` / `Space` / `PageDown`(다음 주제) · `E`(끝내기 → 게임 홈)는 없앴다 (`H` 예시는 R-78). 룰렛 준비 키(`↑` `↓` `X` `A`)도 이 게임에 없다.

모니터는 주제를 고른 뒤 줄곧 주제 카드다 — 문제는 진행자 화면에만 나온다 (R-65).

- 조작은 모두 진행자 화면 — 주제 버튼 · [🎲 무작위], [첫 문제 ▶] · [다음 문제 ▶] · 목록의 [내기] (골라서 내기 — 게임 화면 키는 없음, R-45) · [다음 주제 ▶] · [예시 표시/숨김] · [끝내기] 버튼. 팀 차례 · 추첨 횟수 · 추첨 완료 화면은 없다.
- 문제를 다 낸 주제는 [🎲 무작위] 후보에서 빠진다 — 진행자 목록에서 직접 고르면 나온다 (`D-26` → R-65).

## 4. 득점 상세 (득점형)

### 4-1. 맞힌 팀 지정 — 정답 공개 후 (R-29)

진행자 화면의 맞힌 팀 버튼 · [없음] 으로, **정답 공개 화면에서만** 센다 (게임 화면 `1`~`4` · `0` 은 R-81 에서 없앰). 문제당 맞힌 팀 최대 1팀 (선착순, `D-2`).

| 상황 | 동작 |
| --- | --- |
| 아직 맞힌 팀 없음 | 해당 팀 +1 |
| 같은 팀 다시 | 변화 없음 |
| 다른 팀이 이미 지정됨 | **맞힌 팀 교체** (기존 −1, 새 팀 +1) + 토스트 "맞힌 팀 변경: 팀A → 팀C" |
| [없음] | 지정된 팀이 있으면 그 팀 −1, "정답자 없음" |
| 아무것도 지정하지 않고 게임 화면 `Enter` 로 다음 | 확인창 "맞힌 팀(정답자)을 체크하지 않았습니다. 이대로 다음으로 넘어갈까요?" — 실수로 세지 않고 넘기는 것을 막는다 (R-86). 진행자 화면 [다음 문제 ▶] · [라운드 종료 ▶] · (추가 문제) [결과로 ▶] 도 같은 내용을 진행자 화면에 묻는다 (R-87) |
| 릴레이(R-62) — 그 문제 전에 대표를 모두 내보낸 팀 | 무시 + 토스트 "팀A — 대표가 모두 맞혀 이번 라운드에서 빠졌습니다" (진행자 화면에서는 버튼이 꺼져 있음) |

### 4-2. 취소 · 고치기
- 득점 취소: 진행자 화면 [없음] (게임 화면 `Shift + 1~4` 는 R-81 에서 없앰).
- 되돌리기는 없다 — 진행자 화면 [↶ 되돌리기] 는 R-60, 게임 화면 `Backspace` 는 R-83 에서 없앴다. 둘 다 화면과 상관없이 게임 전체의 **마지막 점수 변경**을 지워서, 라운드 소개 · 정답 공개 전 문제 화면에서 누르면 지난 라운드 · 직전 문제 점수가 보이지 않게 지워졌다.
- 진행자 화면에서는 정답 화면의 맞힌 팀 버튼으로 바로 고치고, 지난 문제는 머리줄 [📝 정답 기록] 에서 고친다 ([12-host-view.md](12-host-view.md) 4-10, R-60).

### 4-3. 추가 문제 (동점 처리, `D-3`)
- 추가 문제는 진행자 화면에서 고른다 — 결과 패널의 추가 문제 고르기 (카테고리 → 문제 [내기], R-54). 게임 화면 `S`(무작위)는 R-85 에서 없앴다. 열린 추가 문제는 문제 화면과 같은 조작 (`Enter` · 진행자 [힌트 단계 ▶] · [💡 힌트]).
- 화면 위에 "추가 문제 — 팀A · 팀B 동점" 표시. 지금 가리는 동점 그룹 팀만 맞힌 팀으로 지정 가능 (다른 팀은 무시 + 토스트 "동점 팀만 참여합니다").
- 추가 문제 정답은 정답 수에 더하지 않고 동점 그룹 안 순서만 정한다.
- 정답 공개 후 `Enter` (진행자 [결과로 ▶]) → 결과 화면 (재계산된 순위). 아직 동점이 남아 있으면 진행자 화면에서 다시 고른다.
- 더 열 문제가 없으면 동점 안내 대신 "추가 문제가 없어 공동 순위로 정합니다".

## 5. 타이머 — 없음 (R-33)

- 득점형 타이머는 없앴다 (`D-20`). `T` · `Shift + T` 는 아무 동작도 하지 않는다.
- 문제를 얼마나 끌지는 연출 단계(진행자 [힌트 단계 ▶])와 진행자의 [정답 공개]로 정한다.
- 장 번호는 다른 문서의 참조(6 · 7장)를 지키려고 남겨 둔다.

## 6. 연출 단계 (진행자 [힌트 단계 ▶] / [◀]) 상세

진행자 화면 [힌트 단계 ▶] 는 모든 득점형 문제에서 "한 단계 힌트" 다 — 게임 화면 키 `Z` / `Shift+Z` 는 R-78 에서 없앴다. 무엇이 바뀌는지는 문제 연출에 따른다 ([07-state-model.md](07-state-model.md) 5-1 표).

### 6-1. `photo` 확대 (`effect: "zoom"`)
- 진입 시 최대 확대(단계 0).
- 단계 `k` 배율 = `zoom ^ (1 − k / steps)` (등비 감소). 예) `zoom 6, steps 3` → 6.0 → 3.3 → 1.8 → 1.0
- [힌트 단계 ▶] 단계 +1 (최대 `steps` = 원본), [◀] 단계 −1 (최소 0).
- 확대 중심 = `focus`. 가장자리 지점이어도 이미지 밖 빈 공간이 보이지 않게 중심 자동 보정.
- 정답 공개 시 원본으로.

### 6-2. `photo` 가림 (`effect: "mask"`)
- 진입 시 가림 상자가 모두 덮인 상태.
- [힌트 단계 ▶] 상자 하나 제거 (배열 순서대로, 0.4초 페이드 — **마지막 상자는 남김**, R-42), [◀] 마지막으로 제거한 상자 다시 덮기.
- 정답 공개 시 남은 상자 모두 제거.

### 6-3. `photo` 원본 (`effect: "none"`)
- [힌트 단계 ▶] · [◀] 변화 없음.

### 6-4. `emoji` 순차 공개
- `reveal: "sequential"` 문제는 진입 시 첫 이모지만 공개 (단계 1).
- [힌트 단계 ▶] 하나 더 공개 (최대 = 이모지 수), [◀] 하나 숨김 (최소 1).
- 공백은 공개 단위에 포함하지 않음 (이모지만 셈).
- 정답 공개 시 전부 공개.

## 7. 진행자 화면 (정답 확인)

- 진행자는 정답 확인과 진행 조작을 **진행자 화면**(`/host`)에서 한다 (R-19, R-26, R-29, [12-host-view.md](12-host-view.md)). 인쇄용 정답지 기능(`P`)은 만들지 않는다.
- 여는 법: 게임 화면 ☰ → "진행자 화면" → 새 창 (노트북 화면으로 옮김). PIN 은 서버 터미널에서 확인.
- 진행자 화면은 **진행 조작 패널**이다 — 버튼 목록은 [12-host-view.md](12-host-view.md) 4장. 키보드: `B` 가리기 토글.

## 9. 무선 프리젠터

- 대부분 `PageUp` / `PageDown` 또는 `←` / `→` 를 보낸다 → **게임 화면은 이 키를 쓰지 않는다** — 넘기기는 모두 `Enter` (R-79 · R-82 · R-85), 이전 `←` · `PageUp` 은 R-74 에서 없앰. `Enter` 를 보내는 프리젠터만 넘어간다.
- 일부 프리젠터의 "검은 화면" 버튼(`.` 또는 `B`) 은 무시.
- 기본 진행은 진행자 화면 버튼이므로 프리젠터는 쓰지 않아도 된다.

## 10. 공개 모드 `/play` (R-96 · R-98 · R-99 · R-103)

진행자 화면 없이 혼자 하므로 **모든 단계를 키보드와 마우스 둘 다로** 한다 (행사용 게임 화면의 "버튼 없음 · 키 최소" 원칙은 `/` 에만). 키는 `Enter` · `H` · `Esc` 와 목록의 방향키뿐 — `Enter` 는 언제나 그 화면의 주 버튼(주황), `H` 는 힌트, `Esc` 는 한 단계 위. 버튼에 키 이름이 붙어 있다.

| 화면 | `Enter` | `H` | `Esc` | 그 밖 |
| --- | --- | --- | --- | --- |
| 게임 목록 | 고른 게임의 카테고리 목록 | — | — | `←` `↑` 앞 · `→` `↓` 뒤 (끝에서 처음으로 돈다) · 카드 클릭 |
| 카테고리 목록 (R-98) | 고른 카테고리 — 풀던 것은 이어서, 아니면 새 판 | — | 게임 목록 | 방향키 · 카드 클릭은 게임 목록과 같음 |
| 문제 | [정답 보기] | [💡 힌트 (n)] — 한 단계(확대 축소 · 가림 상자 · 이모지 하나), 다 쓰면 힌트 글. 남은 힌트가 없으면 버튼이 없고 키도 무시 | 카테고리 목록 (위치는 저장됨) | |
| 정답 | 정답 영상이 덮고 있으면 [⏭ 영상 넘기기], 아니면 [다음 문제 ▶] · [끝 ▶] | — | 같음 | 영상 위를 클릭하면 소리가 켜진다 (자동 재생 정책 — 4-7) |
| 모두 풀었습니다 | [카테고리 목록] | — | 카테고리 목록 | [다시 풀기] 는 버튼 (Tab 으로 고르고 Enter 도 됨) |

- 마우스로 누른 버튼에는 포커스를 남기지 않는다 — 다음 `Enter` 가 그 버튼을 또 누르지 않고 화면의 주 버튼으로 간다. `Tab` 으로 고른 버튼은 `Enter` · `Space` 로 그 버튼이 눌린다 (화면 키가 한 번 더 움직이지 않음).
- `Cmd` · `Ctrl` · `Alt` 가 함께 눌린 키와 누르고 있는 반복(`event.repeat`)은 무시 (1장과 같음). 전체화면 · 메뉴 키는 없다 (브라우저 전체화면을 쓴다).
- **브라우저 뒤로 · 앞으로 가기** (R-99): 뒤로 가기는 `Esc` 와 같이 한 단계 위로 (문제 → 카테고리 목록 → 게임 목록), 앞으로 가기는 다시 아래로. 휴대폰 뒤로 가기도 같다.
- 문제 화면 **[↺ 처음부터]** (R-99) 는 버튼만 — 키는 없다 (실수로 위치를 잃지 않게). `Tab` 으로 고르고 `Enter` 는 된다.
- 게임 목록 **[↺ 이어하기 초기화]** (R-103) 도 버튼만 — 키는 없고 확인창을 거친다.
