## 2. 공통 레이아웃

기준 해상도 1920×1080 (16:9). 크기는 화면 높이 비례(`vh`)로 잡아 다른 해상도에서도 비율 유지.

### 2-1. 진행 화면 (문제 · 정답)

```
┌──────────────────────────────────────────────────────────────┐
│ ☰  헤더 (8vh)   게임 · 라운드 이름                     Q 3/5 │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                 메인 영역 (76vh)                              │
│                 사진 / 이모지 / 정답                          │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 스코어보드 (16vh)   [팀1 점수]   [팀2 점수]   [팀3 점수]       │
└──────────────────────────────────────────────────────────────┘
```

사진 보고 맞추기 (R-53, `D-32`) — 스코어보드를 머리줄 아래 **오른쪽 세로 열**로:

```
┌──────────────────────────────────────────────────────────────┐
│ ☰  헤더 (8vh)   게임 · 라운드 이름                     Q 3/5 │
├─────────────────────────────────────────────────────┬────────┤
│                                                     │  팀1   │
│                                                     │   3    │
│            메인 영역 (92vh × (100vw − 16vh))         ├────────┤
│            사진 / 정답                               │  팀2   │
│                                                     │   1    │
│                                                     ├────────┤
│                                                     │  팀3   │
│                                                     │   0    │
└─────────────────────────────────────────────────────┴────────┘
                                                  스코어보드 (폭 16vh)
```

- 이모티콘 퀴즈는 위 그림(아래 띠)대로, 사진 보고 맞추기는 오른쪽 열. 추가 문제 화면도 그 게임의 배치를 따른다.
- 오른쪽 열 폭 16vh = 1080p 에서 173px. 1920×1080 에서 사진 칸이 1920×720 → 1747×892 — 세로 · 정사각 · 16:9 사진은 24% 커지고, 가장 넓은 사진(2.42:1)도 아래 띠 때보다 작아지지 않는다. 열이 179px 를 넘으면 그 사진이 작아진다 (`D-32`).

### 2-2. 그 밖의 화면
- 제목 · 게임 홈 · 룰렛 · 라운드 소개 · 라운드 종료 · 결과 · 주제 카드는 헤더 · 스코어보드 없이 전체를 쓴다.
- 단, 룰렛(득점형)은 하단에 작은 현재 점수 띠(6vh) 표시.

### 2-3. 공통 규칙
- ☰ 버튼은 **모든 화면 좌상단에 항상** 표시 (44×44px 이상, 반투명). 전체화면 진행 중에는 마우스를 3초 움직이지 않으면 커서와 함께 흐려짐(투명도 0.2), 마우스를 움직이면 다시 보임.
- 좌우 여백: 화면 너비의 3%.
- 스크롤 금지 (`overflow: hidden`). 단 게임 홈 · 팀 설정은 내용이 길면 내부 스크롤 허용 (관리 페이지는 별도 페이지라 일반 웹 페이지처럼 스크롤).

| ~~요약 줄~~ | R-92 로 없앰 — 포함 카테고리 수 · 라운드 · 팀당 대표 요약은 참여자가 알 필요 없음 (진행자는 관리 페이지 · 진행자 화면에서) |

### 4-4. 룰렛 (R-5, R-21)

룰렛 화면은 **준비 → 회전 → 당첨** 세 단계다. 룰렛을 돌릴 때마다 항상 준비 단계부터 시작한다 ([01-app-flow.md](01-app-flow.md) 5-2).

#### 준비 단계 — 이번 판에 넣을 카테고리 고르기

넣기 · 빼기는 **진행자 화면 목록**에서 한다 (12-host-view 4-2). 게임 화면은 넣은 카테고리로 만든 **원판만** 보여 준다 — 목록 · 커서가 있으면 결과를 고르는 것처럼 보이므로 두지 않는다 (R-72).

```
┌──────────────────────────────────────────────────────────────────┐
│ ☰                    ROUND 2 카테고리 추첨                         │
│                                ▼                                 │
│                          ╭──────────╮                            │
│                        ╱  🧸  │  🔍  ╲                           │
│                       │──────●──────│   (넣은 카테고리만)        │
│                        ╲  💬  │  🍪  ╱                           │
│                          ╰──────────╯                            │
│                     지난 라운드: 🔍 확대 음식                      │
├──────────────────────────────────────────────────────────────────┤
│  팀A 3   팀B 2   팀C 1                                (점수 띠)    │
└──────────────────────────────────────────────────────────────────┘
```

| 요소 | 규칙 |
| --- | --- |
| 머리 | "ROUND n 카테고리 추첨" — 부제 없음 |
| 원판 미리보기 (가운데) | 넣은 카테고리만 조각으로. 진행자가 넣거나 빼면 0.2초 안에 다시 그림 |
| 지난 라운드 | 원판 아래 칩 (예: "지난 라운드: 🔍 확대 음식") |
| 아래 점수 띠 | 팀별 정답 수 (점수를 주는 게임은 점수, R-49). 릴레이는 팀별 **게임 점수** "팀A 150점" (라운드 배점 합, R-62) |
| 없는 것 (R-72) | 카테고리 목록(● 넣음 / ○ 빠짐 · 남은 수 · ×당첨 횟수) · 키보드 커서 · 조작 안내 — 모두 진행자 화면에만. 모두 출제함 · 부족(릴레이 — `D-33`)도 진행자 화면 목록에 ("모두 출제함" · "부족 · 남은 3/4") |
| 넣을 수 있는 것이 없을 때 | 준비 대신 "더 출제할 문제가 없습니다" + "모든 카테고리의 문제를 다 냈습니다" (릴레이는 "한 라운드(4문제)를 낼 만큼 문제가 남은 카테고리가 없습니다"). 키 안내(예전 "— → 결과 보기")는 모니터에 쓰지 않는다 (R-79) |
| 넣은 카테고리 0개 | 원판이 비고, "카테고리를 1개 이상 넣으세요" 는 진행자 화면에 표시 |

#### 회전 · 당첨 단계

```
┌──────────────────────────────────────────────────────────────┐
│ ☰            ROUND 2 카테고리 추첨                            │
│                         ▼  (포인터)                           │
│                  ╭──────────────╮                             │
│               ╱   🧸 캐릭터  │  🔍 확대  ╲                     │
│              │   이름        │   음식     │                    │
│              │──────────────●──────────│                     │
│               ╲   💬 명대사  │  🍪 과자  ╱                       │
│                  ╰──────────────╯                             │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

| 요소 | 규칙 |
| --- | --- |
| 전환 | 진행자 [룰렛 돌리기] (비상용 `Enter`) → 원판이 커지며 회전 시작 |
| 원판 | 지름 = 메인 영역 높이의 80%. 조각 수 = 넣은 카테고리 수, 같은 각도. 이미 나온 카테고리도 넣었다면 그대로 있다 (R-16) |
| 조각 | 팔레트 색 + 아이콘 + 이름. 8개 이하: 아이콘(크게) 위 · 이름 아래 (길면 2줄). 9개 이상: 이름을 반지름 방향으로 눕혀 쓰고(바깥 → 가운데) 아이콘은 바깥 끝 — 사진 퀴즈 14칸에서도 읽히게. 그래도 넘치면 말줄임 |
| 조각 색 | 팔레트 8색 순환. 조각 수를 8로 나눈 나머지가 1이면(9 · 17개) 마지막 조각은 색 하나를 건너뛰어 첫 조각과 같은 색이 붙지 않게 |
| 포인터 | 원판 위 가운데 `--accent` 역삼각형. 조각 경계를 지날 때 살짝 튕김 |
| 가운데 | 원형 허브 (게임 아이콘) |
| 헤더 | "ROUND n 카테고리 추첨" — 득점형만. 룰렛형(줄줄이 말해요)은 원판이 없다 (R-65 — 아래 "주제 고르는 중") |
| 안내 문구 | 없음 — 조작은 진행자 화면 [확정] · [다시 돌리기] (비상용 키 `Enter` 확정 · `Backspace` 다시 돌리기 — R-26 · R-79 · R-84) |
| 당첨 표시 | 당첨 조각 밝게 + 흰 테두리 + 나머지 조각 어둡게. 0.5초 뒤 가운데 큰 카드: 아이콘 + "ROUND 2" + 카테고리 이름 (룰렛형은 "ROUND" 없이 주제 이름) (팝업 0.4초) |
| 넣은 카테고리 1개 | 회전 없이 그 카테고리 카드 바로 표시 |
| 다시 돌리기 | 정지 후 진행자 [다시 돌리기] · 게임 화면 `Backspace` (R-84) → 준비 단계로 돌아감 (선택 유지, 방금 결과는 버림) |

- 회전 연출: 4~6초, 최소 4바퀴, ease-out cubic. 조각이 많아도(최대 20) 60fps 유지 — canvas 또는 CSS transform 회전 1개 요소로 구현.

### 4-5. 라운드 소개 (득점형)

| 요소 | 내용 |
| --- | --- |
| 라운드 번호 | "ROUND 2" (`--accent`) |
| 안내 문장 | "두 번째 게임은" (ROUND 1 = "첫 번째 게임은", 2 = "두 번째 게임은" …) — 진행자가 그대로 읽을 수 있게 (`D-4` 진행 예) |

| 진입 효과 | 슬라이드 업 + 페이드 (0.5초) |

### 4-7. 정답 공개 (득점형)

| 요소 | 내용 |
| --- | --- |
| 메인 | `photo`: 확대 해제(0.6초) · 남은 가림 상자 제거(0.4초 페이드) → 정답 이미지가 있으면 교차 페이드(0.4초) — 정답 이미지는 **원본 비율 그대로** 메인 영역에 가장 크게 · 가운데, 문제 사진은 사라진다 (비율이 달라도 늘어나지 않음, R-59) / `emoji`: 남은 이모지 모두 공개 → 정답 이미지가 있으면 교차 페이드(0.4초, R-39) |
| 정답 영상 (`answerClip`, R-61 — `photo` 만) | 정답 공개와 함께 **메인 영역을 영상이 덮고 자동 재생** (0.4초 페이드 인, 16:9 를 메인 영역에 가장 크게 · 가운데, 남는 곳은 배경색). 지정한 구간(시작 ~ 끝)만 재생하고 **끝나면 영상을 걷어내(0.4초)** 그 아래에서 끝난 사진(확대 · 가림 해제 · 정답 이미지)과 **정답 띠**가 나온다 — 영상이 덮고 있는 동안은 정답 띠(정답 글자 · 맞힌 팀)를 띄우지 않는다. 진행자 화면 [⏸ 일시정지] · [▶ 계속] · [⏭ 영상 끝내기] · [↺ 영상 다시 재생] (다시 재생하면 정답 띠는 다시 숨었다가 끝나면 나옴 — [../12-host-view.md](12-host-view.md) 4-2). 영상 위 마우스에 유튜브 단추가 뜨지 않게 투명 막을 덮는다. 브라우저가 소리를 막으면(게임 화면을 연 뒤 한 번도 클릭 · 키 입력이 없을 때) 소리 없이 재생하고 아래에 "🔇 소리가 꺼져 있습니다 — 이 화면을 한 번 클릭하면 소리가 켜집니다" — 클릭하면 이어서 소리. 영상을 못 틀면(인터넷 · 퍼가기 금지 · 삭제) 영상 없이 바로 정답 띠 (이유는 진행자 화면에만). 정답 화면으로 **바로 들어온 경우**(새로고침 · 이어하기 · 라운드 종료에서 돌아옴)는 자동 재생하지 않는다 — 진행자 화면 [▶ 영상 재생] |
| 정답 글자 숨기기 (`hideAnswerText`, R-41 · R-47) | 정답 띠를 띄우지 않는다 — 정답 이미지가 있으면 그것만, 없으면 원래 사진(확대 · 가림 해제)만. 맞힌 팀을 지정하면 그 자리에 작은 띠로 "✔ 팀A +1" · "정답자 없음" |
| 정답 | 메인 하단 1/3 지점 반투명 띠 + 정답 텍스트 (`--accent`, 대형, 길면 2줄). 연출이 끝난 뒤 팝업 (0.3초) |
| 질문 문구 | 그대로 유지 |
| 맞힌 팀 | 처음엔 비어 있다. 진행자가 진행자 화면에서 맞힌 팀을 고르면 정답 아래 "✔ 팀A +1" (팀 색, 팝 0.4초) + 스코어보드 그 팀 +1 효과. 다른 팀으로 바꾸면 표시 교체 · 원래 팀 −1. [없음] 이면 "정답자 없음" (R-29). 점수를 주는 게임(이모티콘 퀴즈, R-49)은 "✔ 팀A +50". 릴레이(R-62)는 "✔ 팀A 1/2" (이번 라운드 맞힌 대표 수 / 대표 수 — 인당 문제가 2 이상이면 맞힌 문제 수 / 대표 × 인당 문제 "✔ 팀A 3/4", R-64), 그 문제로 대표를 모두 내보냈으면 "✔ 팀A — 🥇 1등 확정". **R-94**: 맞힌 사람(대표)까지 — "✔ 팀A 대표2 1/2" (그 대표가 맞힌 수 / 인당 문제), 이 문제로 그 사람이 빠지면 "✔ 팀A 대표1 2/2 · 빠짐" (인당 1 이면 "✔ 팀A 대표1 · 빠짐"). 같은 팀 다른 대표로 바꾸면 표시만 바뀐다 |
| 공개 시점 | 진행자 화면 [정답 공개] 를 눌렀을 때만 — 누가 맞혔든, 이 문제를 끝내기로 했든 (R-26) |
| 다음으로 (게임 화면 `Enter`) | 맞힌 팀도 [없음] 도 지정하지 않았으면 확인창 "맞힌 팀 확인 — 맞힌 팀(정답자)을 체크하지 않았습니다. 이대로 다음으로 넘어갈까요?" [취소 (Esc)] [넘어가기 (Enter)] (R-86) — 모니터에 뜬다 |
| 힌트 | 표시 중이면 화면 상단으로 이동 |

| 하단 버튼 | 없음 (게임 화면은 보여주기 전용, R-26). 다른 화면으로는 ☰ 메뉴로 이동 |

### 4-9. 주제 카드 · 문제 (룰렛형)

주제 고르는 중 (R-65 — 원판 없음): 게임 아이콘 · 이름 (주제 카드와 같은 크기) + "주제를 뽑아 주세요" (R-88) + 지난 주제 칩 (최근 8개). 후보 주제 이름 · 남은 문제 수는 보이지 않는다 — 미리 보이면 팀이 답을 준비할 수 있으므로. 진행자가 고르는 순간 아래 주제 카드로 바뀐다.

주제 카드:

| 요소 | 내용 |
| --- | --- |
| 아이콘 · 주제 | 화면 중앙 대형 (110px) |
| 규칙 문구 | 아래 44px |
| 예시 | 진행자 [예시 표시] 로 토글 (게임 화면 `H` 는 R-78 에서 없앰), 하단 칩 목록 (기본 숨김) |

| 언제 나오나 | 주제를 고르면 언제나 — 문제가 있는 주제도, 문제를 내는 동안에도 그대로 (문제 · 정답 후보는 진행자 화면에만, R-65) |

문제 (주제에 문제가 있을 때, R-44) — **R-65 부터 게임 화면에 나오지 않는다** (문제 · 정답 후보는 진행자 화면에만). 아래 모양은 관리 페이지 문제 편집 미리보기에만 남는다:

```
┌──────────────────────────────────────────────────────────────┐
│                 📜 앞 두 글자로 네 글자                         │  ← 아이콘 · 주제 5.5vh
│        앞 두 글자를 보고 네 글자 낱말을 하나씩, 중복 금지         │  ← 규칙 3vh, 흐리게

└──────────────────────────────────────────────────────────────┘
```

| 요소 | 내용 |
| --- | --- |
| 아이콘 · 주제 · 규칙 | 위쪽 가운데, 작게 (주제 5.5vh · 규칙 3vh `--text-dim`) — 어느 주제인지만 보이게 |

| 정답 후보 | 예전 `H` 토글 — 지금은 모니터에 안 나오고 `H` 도 R-78 에서 없앰 (기본 숨김, 문제가 바뀌면 다시 숨김). 하단 칩 목록, 가나다순. 많으면 여러 줄 |

| 전환 | 문제가 바뀔 때마다 화면 전환(0.3초 페이드), 문제 글자는 팝업(0.4초) |

### 4-10. 스코어보드 — 팀별 정답 수 (득점형 진행 화면 공통)

- 게임 안의 스코어보드는 **정답 수**만 보여준다 (R-22). 종합 점수는 별도 화면인 종합 점수판([13-scoreboard.md](13-scoreboard.md))에서 다룬다.
- 예외 (R-49): 점수판 "정답 수" 라운드가 게임 전체에 연결된 게임(기본값 이모티콘 퀴즈)은 **점수**(정답 수 × 1개당 점수)를 보여주고, 득점 효과가 "+50" 처럼 1개당 점수로 떠오른다. 룰렛 화면 아래 정답 띠(4-4)도 점수.
- 예외 (R-62, 사진 릴레이): 팀마다 정답 수 대신 **이번 라운드 진행** — 맞힌 대표 ●, 남은 대표 ○ (대표 2명이면 "●○"). 인당 문제가 2 이상이면 ●○ 가 맞힌 문제 하나씩이고 **대표마다 한 줄** — 2명 × 2문제에 3개 맞힘이면 윗줄 "●●" · 아랫줄 "●○" (R-64. 한 줄에 4개를 두면 1920×1080 오른쪽 열에서 잘린다). 대표를 모두 내보낸 팀은 "🥇 1등" 처럼 등수 메달, 지금 문제에 못 나오는 팀(그 문제 전에 다 내보낸 팀)은 흐리게. 👑 없음. **R-94**: 대표마다 한 묶음 — 묶음 앞에 작은 번호(1 · 2)와 **그 사람이 맞힌** ●, 오른쪽 열에서는 대표마다 한 줄 (인당 1 이어도 묶음 "1●" / "2○"). 정답 화면에서는 **묶음을 클릭하면 그 사람이 맞힌 것으로** (진행자 화면 버튼과 같음) — 고를 수 있는 묶음은 팀 색 테두리, 이 문제를 맞힌 묶음은 채운 바탕, 인당 문제를 채운 사람 · 빠진 팀은 테두리 없이 눌리지 않는다. 묶음 글자 크기는 세 팀이 같다 (칸 높이에 맞춰 줄이고 가장 작은 크기로 맞춤 — 맞힌 팀 ✔ 로 한 팀만 작아지지 않게). 추가 문제 화면은 대표 규칙이 없어 동점이 된 게임 점수(라운드 배점 합)를 보인다.

| 요소 | 내용 |
| --- | --- |
| 배치 | 아래 띠: 팀 수만큼 같은 폭. 오른쪽 열 (사진, R-53): 팀 수만큼 같은 높이로 위아래로 쌓고 카드 안은 이름 위 · 정답 수 아래, 가운데 정렬 |
| 팀 카드 | 왼쪽 팀 색 세로 띠(8px) + 팀 이름 + 점수(대형) + 단축키 숫자(작게) |
| 이 문제 득점 | 팀 색 배경(투명도 25%) + ✔ |
| 득점 효과 | 숫자 팝(0.4초) + 테두리 반짝임 + "+1" 떠오름 |
| 취소 효과 | 숫자 흔들림 (0.3초) |
| 단독 선두 | 작은 👑 |
| 클릭 | 반응 없음 — 맞힌 팀 지정은 진행자 화면에서 정답 공개 후 (R-29) |
| 팀 이름 길이 | 10자까지 한 줄 (넘치면 글자 축소). 오른쪽 열에서는 두 줄까지 나눈 뒤 축소, 정답 수도 칸 폭에 맞춰 축소 |

### 4-11. 라운드 종료 (득점형, R-56)

라운드 마지막 문제(릴레이는 한 팀만 남았거나 카테고리 문제가 떨어진 문제 — R-62)의 정답 공개 뒤 진행자가 [라운드 종료 ▶] (비상용 `Enter`, R-85) 를 누르면 나오는 화면. 진행자 화면에는 그 전에 "라운드가 종료되었습니다" 안내와 [한 문제 더 ▶] · [라운드 종료 ▶] 가 먼저 뜬다 ([12-host-view.md](12-host-view.md) 4-9).

```
┌──────────────────────────────────────────────────────────────┐
│                  ROUND 2 · 🍪 과자 이름                        │  ← --accent 5vh
│                 라운드가 종료되었습니다                          │  ← 9vh, 900
│                     이번 라운드 점수                            │  ← 3vh, 흐리게
│   ┌──────────┐    ┌──────────┐    ┌──────────┐                │
│   │👑 팀A    │    │  팀B     │    │  팀C     │                │  ← 팀 색 세로 띠
│   │    3 개  │    │    1 개  │    │    0 개  │                │  ← 이번 라운드 16vh
│   │ 누적 5개 │    │ 누적 4개 │    │ 누적 1개 │                │  ← 3vh, 흐리게
│   └──────────┘    └──────────┘    └──────────┘                │
└──────────────────────────────────────────────────────────────┘
```

| 요소 | 내용 |
| --- | --- |
| 라운드 | "ROUND 2 · 🍪 과자 이름" (`--accent`). 계획을 넘긴 라운드도 번호만 ("ROUND 4") |
| 제목 | "라운드가 종료되었습니다" (가장 크게) |
| 팀 카드 | 팀 수만큼 같은 폭, 팀 순서대로 (순위로 섞지 않음). 왼쪽 팀 색 세로 띠 + 팀 이름 + **이번 라운드 점수** (가장 크게) + 아래 작게 "누적 5개" |
| 점수 | 이번 라운드의 팀별 정답 수 ("3개") — 그 라운드에 한 문제 더로 낸 문제 포함, 추가 문제(동점) 제외. 점수를 주는 게임(R-49, 이모티콘 퀴즈)은 점수 ("150점") + 누적도 점수 ("누적 250점") |
| 1위 표시 | 이번 라운드 점수가 단독으로 가장 높은 팀 카드에 👑 + 팀 색 테두리. 모두 0 이거나 공동이면 없음 |
| 진입 효과 | 제목 슬라이드 업 (0.5초), 팀 카드는 차례로 솟아오름 (0.1초 간격) |
| 릴레이 (R-62, 사진) | 라벨 "이번 라운드 순위". 팀 카드에 메달 + "1등" (가장 크게), 아래 작게 "맞힌 대표 2/2" (인당 문제가 2 이상이면 "맞힌 문제 4/4", R-64) — 누적 정답 수 줄은 없다. 1등 팀(단독)에 👑 + 팀 색 테두리. 정답이 하나도 없는 라운드는 "등수 없음". 반영하면 "종합 450 (+100)" 은 그대로 |
| 종합 점수 (R-57) | 진행자가 [팀 점수에 반영] 하면 카드마다 "종합 450 (+100)" (종합 점수판 합계, 괄호는 이번 라운드가 더한 점수 — 연결된 행 모두) + 카드 아래 "종합 점수판에 반영했습니다". 반영 전 · 계산이 달라졌을 때는 표시하지 않는다 |
| 점수 바뀜 | 진행자가 [📝 정답 기록] 으로 맞힌 팀을 고치면(R-60) 다시 계산해 그린다 |
| 하단 버튼 | 없음 (R-26). 다음 라운드 · 결과 보기 · 한 라운드 더 · 라운드로 돌아가기는 진행자 화면 |

### 4-12. 기록 · 통계 (R-58)

☰ 메뉴 → **📊 기록 · 통계**. 모니터로 참가자에게 보여주는 화면이라 글자를 크게 한다 (1080p 기준 본문 3vh 이상). 보기 전용 — 진행 기록 · 점수판은 바꾸지 않는다.

```
┌──────────────────────────────────────────────────────────────┐
│ ☰  📊 기록 · 통계     [📈 종합 점수 추이] [👥 팀별 통계] [📝 문제 기록] │  ← 탭 (1 · 2 · 3, →)
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   (탭 내용 — 넘치면 ↑ ↓ · 마우스 휠로 넘김)                      │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

| 탭 | 내용 |
| --- | --- |
| 📈 종합 점수 추이 | 왼쪽: 꺾은선 그래프 — 가로축 = 종합 점수판 기록 순서 (처음 0점 → 기록마다 한 점, 아래에 그때 바뀐 행 이름 — 길면 줄임), 세로축 = 종합 점수, 팀마다 팀 색 선 · 점, 선 끝에 팀 이름 · 점수. 오른쪽: 지금 순위 카드 (순위 · 팀 · 합계, 1위 👑). 기록이 없으면 "아직 종합 점수판에 들어간 점수가 없습니다" (점수가 있는데 기록이 없으면 — R-58 전에 넣은 점수 — "지금" 한 점만) |
| 👥 팀별 통계 | 위: 팀 카드 (팀 색 띠 · 팀 이름 · **종합 점수 · 순위** · 퀴즈 정답 합계 · 라운드 1위 n번 · 게임별 "📸 정답 5개"). 아래: 득점형 게임마다 표 — 행 = 라운드 ("ROUND 1 · 🍔 확대 음식"), 열 = 팀, 값 = 그 라운드 정답 수 (라운드 단독 1위는 팀 색 굵게), 마지막 행 합계, 표 제목 옆 "문제 15개 · 정답자 없음 2개". 아직 하지 않은 게임은 "아직 진행하지 않음" |
| 📝 문제 기록 | 득점형 게임마다(데이터 순서) 라운드별 칸: 머리 "ROUND 1 · 🍔 확대 음식" + 그 라운드 팀별 정답 수, 문제마다 한 줄 "Q1 떡볶이 — ✔ 팀A" (팀 색) · "정답자 없음" · "기록 없음". 한 문제 더(R-43)로 낸 문제도 그 라운드에. 추가 문제(동점)는 "추가 문제" 칸. 줄줄이 말해요는 "뽑힌 주제" (주제 · 횟수) 와 주제마다 낸 문제 글자 |
| 릴레이 게임 (R-62) | 팀별 통계의 "라운드 1위" 와 라운드 표의 단독 1위 강조는 정답 수가 아니라 **라운드 1등** (대표를 가장 먼저 모두 내보낸 팀). 표 값은 정답 수 그대로 |
| 문제 기록 — 감추기 | **아직 내지 않은 문제는 보이지 않는다** (라운드를 확정할 때 뽑아 둔 그 라운드의 남은 문제 포함). 지금 문제가 정답 공개 전이면 정답 대신 "진행 중" |
| 넘김 | 내용이 화면보다 길면 탭 내용 칸만 `↑` `↓` · `PageUp` `PageDown` · 마우스 휠로 넘긴다 |

### 4-13. 문제 고르기 — 이모티콘 퀴즈 (R-90)

룰렛 대신. 게임 시작 직후와 진행자 [카테고리 목록 ▶] (정답 화면에서 `Enter`) 뒤에 나온다. 게임 화면에서 카테고리 카드를 클릭하거나(R-91) 진행자가 진행자 화면에서 문제를 골라 [내기] 하면 라운드 소개 없이 바로 문제 화면.

```
┌──────────────────────────────────────────────────────────────┐
│                     😀 이모티콘 퀴즈                          │
│                   카테고리를 골라 주세요                       │
│   ┌──────────┐   ┌──────────┐   ┌──────────┐                 │
│   │    🎬    │   │    📜    │   │    🎵    │                 │
│   │   영화   │   │   속담   │   │ 노래 제목 │                 │
│   │남은 문제 3│   │남은 문제 4│   │  모두 냄  │ ← 흐리게        │
│   └──────────┘   └──────────┘   └──────────┘                 │
├──────────────────────────────────────────────────────────────┤
│        ● 호랑이 50   ● 사자 100   ● 곰 0                      │
└──────────────────────────────────────────────────────────────┘
```

| 요소 | 규칙 |
| --- | --- |
| 카테고리 카드 | 숨김 아닌 · 문제가 있는 카테고리마다 아이콘(9vh) · 이름(5vh) · "남은 문제 n". 이 게임에서 다 낸 카테고리는 투명도 0.35 + "모두 냄". **클릭하면 그 카테고리 문제 하나가 바로 나온다** (문제 순서 옵션대로 — R-91, 마우스를 올리면 테두리 강조). 다 낸 카드는 눌리지 않는다. 특정 문제는 진행자 화면 [내기] |
| 안내 문구 | "카테고리를 골라 주세요" — 문제를 다 냈으면 "모든 문제를 냈습니다" (`Enter` · 진행자 [결과 보기 ▶] 로 결과) |
| 점수 띠 | 아래 띠에 팀별 점수 (정답 수 × 1개당 점수, 룰렛 화면과 같음) |
| 문제 화면 머리줄 | 라운드 대신 "😀 🎬 영화" · 오른쪽 "3번째 문제" (이 게임에서 낸 문제 수) — 4-6 |

## 5. 오버레이

| 오버레이 | 호출 | 내용 | 닫기 |
| --- | --- | --- | --- |

## 7. 공개 모드 `/play` (R-96 · R-97 · R-98 · R-99)

흐름은 [01-app-flow.md](01-app-flow.md) 8장, 키는 [06-controls.md](06-controls.md) 10장. 게임 화면의 디자인 토큰 · 사진 · 이모지 표시(render-photo · render-emoji · 정답 영상)를 그대로 쓰고, 다른 점만 `app/play/play.css` 에 둔다. ☰ 버튼 · 메뉴 · 점수 띠 · 연결 표시가 없다. 휴대폰 폭(375px)에서도 가로 스크롤 없이 쓸 수 있다. 줄줄이 말해요 화면(주제 카드 · 주제 문제)은 없다 (R-97).

| 화면 | 생김새 |
| --- | --- |
| 꺼져 있음 · 불러오지 못함 | PIN 화면과 같은 판 — "🏕️ <행사 제목>" + "지금은 공개하지 않습니다" · "운영자가 공개 모드를 켜면 이 주소에서 게임을 해 볼 수 있습니다." / "불러오지 못했습니다" · "인터넷 연결을 확인한 뒤 새로고침하세요" |
| 게임 목록 | 제목 화면 배경(4-1) 위에 "🏕️ <행사 제목>" · "게임을 골라 혼자 해 보세요 — 점수는 세지 않습니다" · 게임 카드(이모티콘 퀴즈 카테고리 카드 모양 — 아이콘 · 이름 · 설명 · "카테고리 12개 · 문제 56개". 설명은 데이터의 행사용 설명 대신 혼자 하는 문구 (R-99): 사진 "사진을 보고 무엇인지 맞혀 보세요!", 이모티콘 "이모지를 보고 영화 · 속담을 맞혀 보세요!" (숨기지 않은 카테고리 이름), 다 푼 카테고리가 있으면 "✔ 다 푼 카테고리 1 / 12" 배지) · "← → 고르기 · Enter 시작 — 마우스로 눌러도 됩니다" · 남은 진행이 있으면 그 아래 [↺ 이어하기 초기화] (R-103 — 확인창 뒤 이 브라우저의 이어하기 · 다 푼 기록을 모두 지움). 방향키로 고른 카드는 강조 테두리. 넘치면(휴대폰) 세로 스크롤 — 위가 잘리지 않게 |
| 카테고리 목록 (R-98) | 게임 홈(4-3) 머리 — 아이콘 · 이름 · 설명(게임 목록과 같은 혼자 하는 문구 — R-99). 그 아래 혼자 하는 방법 세 줄 (행사 규칙 — 팀 · 대표 — 대신): "카테고리를 고르면 그 카테고리 문제가 모두 정해진 순서대로 나옵니다" (관리 페이지 문제 순서가 작성 순서) / "… 무작위 순서로 나옵니다" (무작위 — R-102) · 사진 "막히면 💡 힌트 — 확대 사진은 한 단계씩 작아지고, 가린 상자는 하나씩 열립니다" / 이모티콘 "… 이모지가 하나씩 더 보이거나 힌트 글이 나옵니다" · "정답을 보고 다음으로 넘어가며 혼자 풀어 보세요 — 점수는 세지 않습니다". 카테고리 카드 — 게임 홈 카테고리 카드 모양(4열, 휴대폰 2열 — 넘치면 카드 영역만 스크롤): 아이콘 · 이름 · 설명 · "문제 4개" + 풀던 카테고리 "이어하기 3 / 4" (주황 배지) · 다 푼 카테고리 "✔ 다 풂" (초록 배지, 이름 흐리게). 방향키로 고른 카드는 강조 테두리 (돌아오면 마지막에 연 카드). 아래 [☰ 게임 목록 Esc] · "← → 고르기 · Enter 시작" |
| 문제 · 정답 | 진행 화면(2-1)에서 점수 띠 대신 **버튼 띠**: 머리줄 왼쪽 게임 · 카테고리 아이콘 + 카테고리 이름, 오른쪽 "3 / 4" (그 카테고리 안). 질문 문구 · 사진(확대 · 가림) · 이모지(순차 공개)는 4-6 과 같다. 버튼 띠 [☰ 카테고리 목록 Esc] ([↺ 처음부터] — 첫 문제가 아닐 때, R-99) … [💡 힌트 (n) H] [정답 보기 Enter]. 휴대폰 폭에서는 버튼이 여러 줄로 접힌다. 정답은 4-7 과 같은 정답 띠(정답 이미지 · 정답 글자 숨기기 · 힌트 띠 위로), 맞힌 팀 줄은 없다. 정답 영상이 있으면 영상이 덮는 동안 [⏭ 영상 넘기기 Enter], 끝나면 정답 띠 · [다음 문제 ▶ Enter] (마지막 문제는 [끝 ▶]) |
| 모두 풀었습니다 | 🎉 · "모두 풀었습니다" · "<게임 아이콘> <게임 이름> · <카테고리 아이콘> <카테고리 이름>" · [다시 풀기] [카테고리 목록 Enter] |

- 버튼마다 오른쪽에 키 이름(`Esc` · `H` · `Enter`)을 작은 테두리 글자로 붙인다 — 키보드로도 된다는 것을 화면에서 알 수 있게.
